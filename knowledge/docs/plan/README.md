# 大观园平面复原——研究稿索引

日期:2026-09-10 | 目录:`docs/plan/`

这一层回答一个问题:**大观园到底长什么样,凭什么这么画。**

做法是"取证 → 判决 → 落图"三段:三路取证(诸家复原方案 / 原文空间证据 / 尺度水系规模)各自带独立核验,
刻意**不下判断**、冲突并列存档;`04-conflicts.md` 一次裁完;裁决联立后落成机读的 `projects/daguanyuan/plan.json`,
再由生成器渲成可审的 `plan.svg`。下游(`scenes/<区域>.json` → 装配器 → `src/`)只读 JSON 与 04 篇速查表。

状态定义(与 `docs/fashi/` 同口径):**通过** = `refuted=false` 且 `severity=ok/unverifiable`;
**存疑** = `severity=imprecise` 或 `refuted=true` 但只是精度/表述问题,核验者原话与更正逐条抄在条目下;
**驳倒** = 结论方向即错,移入章末「已否决」,不得再作建模依据。

## 平面图怎么读

- **坐标**:世界坐标直出,`svg x = x`、`svg y = z`,1 svg 单位 = 1 m;**y 向下 = 南**,故图上"上北下南"。
- **颜色 = 等级**(A 礼制主体 / B 居住院落 / C 园林点景),**线型 = 置信度**(实线 高 / 虚线 中 / 点线 低),
  区域中心同时标了中文名与"X 级·信度 X",一眼能看出哪块是推测出来的。
- **序号 = 十七回游线站次**,圆点落在该区自己的 `entrances` 上(第 n 次到访取第 n 个门:翠嶂 ② 西口入题「曲径通幽处」、⑬ 东口出接大路),
  箭头画在游线折线上表行进方向;正门首尾同点,合并成一颗「1·14」。
- 右下角图例与比例尺,底部一条是**七条不可违约束**(出自 04 篇 §四),任何布局改动后按它复检。
- 每个图元都带 `<title>`,浏览器里悬停可看全名、深度 / 高程 / tier / confidence。

## 取舍原则

1. **四级优先级,严格自上而下**:L1 原文明确陈述 > L2 三家以上复原共识 > L3 单家方案 > L4 本项目推测。下级不得推翻上级。
2. **L1 内部再分层**:完整连续的叙述 > 举例式罗列。十七回是一路走一路说的连续行文,十八回那串自称「等处」,故前者压后者(C-01 怡红院取十七回末站)。
3. **原文对撞时不许用 L1 硬压 L1**:降级到 L2 裁,并把被牺牲的那条原文关系**显式记入代价栏**,不许假装它不存在(C-04)。
4. **能调和就不二选一**,但调和方案本身必须落在某一级上;凭空发明的调和一律归 L4(C-02「环线路程 ≠ 直线距离」、C-05「东北角即北墙的拐角」都是 L1 调和)。
5. **设计立场要显式声明,不许伪装成定论**:东西向的两大歧点(潇湘/怡红、稻香村东西)纸上诸家与两处实建正好相反,本项目取"潇湘西、怡红东南、稻香村西"是**选择**,不是考据结论。
6. **实建两园(北京 / 上海)只作施工与体量参照,不作方位权威**;不采实地原型(恭王府 / 随园 / 圆明园 / 西溪),文本自足(S-14)。
7. **尺度是可调参数,不是硬约束**:三里半三种读法差几倍,500×500 只是两条独立路线的会合点,允许在 437–564 m 内整体缩放。
8. **同名异地硬编码防并**:缀锦阁(大观楼东飞楼)≠ 缀锦楼(迎春居,紫菱洲);蓼风轩 = 藕香榭 = 暖香坞是惜春一处的三名,而藕香榭又兼作公共水亭。
9. **凡进图的东西必须能从 JSON 复算**:`plan.svg` 不手改,图上的面积、周长、路程比全部由生成器当场算,以免图与真源脱节。

## 已知缺口

### 取证层(继承自 03 §附 与 04 §五)

1. **诸家复原图的标注边长(米)全部未取得**——需原书原图,可公开访问页面均无。故本项目只引两个可信数字:童力群 372 亩、北京大观园 12.5 ha。
2. 徐建平《红楼梦贾府建筑布局研究》第三章的诸家名单:微信读书需登录,未见原书。
3. **第 4 回原文未逐字核校**(S-15 梨香院不在园内的依据)。
4. 梁友松、关华山、张良皋、孟庆田、宋鸿文、伯齐诸图:仅见转述,未见原图,不参与裁决。
5. ctext.org 反爬未取得正文,**未做交叉核校**;所用维基文库汇校本 Textquality=50%(未精校、简繁混排),凡称"逐字"处均以此本为准。「花溆二字便妥,何必蓼汀」一句**不在**该本中,如要引须另寻底本。

### 几何层(本次落图暴露的新问题,尚未修)

6. **游线折线与站序在「蓼汀花溆 ↔ 蘅芜苑」一段反序**:`paths[0]` 单程东行,沿线到蘅芜苑门在 41.2%、到蓼汀花溆门在 48.0%,而 `route_ch17` 要求先蓼汀(⑦)后蘅芜(⑧)。原文是过石洞后**折回**盘道上蘅芜苑(`paths[7]` 山上盘道正是这段),折线没画这次折返。修法二选一:折线补折返段,或明确声明折线只表大势、站序以 `route_ch17` 为准。**图上的圆点已按 entrances 落点,不受此影响。**
7. **怡红院(⑫)的入口离游线折线 46 m**,其余各站均 ≤ 17 m。折线在东南角应向怡红院门口收一收。
8. **围墙折线实测周长 1896 m,比"三里半 = 2016 m"短 6.0%**。两条路:认下来(仍在可调带内,但图例上的目标值要改口),或把墙折线整体放大 6%。
9. **两条 L4 推测在图上已画成实体**——大山身份判为翠嶂(C-06)、出水口在南墙近东南角墙下涵洞(S-07),图上用点线框与"信度低"标出,读图时勿当定论。
10. **3 条带代价的裁决在图上不可见**:被牺牲的那几句原文(花瓣流出沁芳闸、村坞紧邻、抄检横穿)只存在于 04 篇的代价栏。
