## 0 本篇怎么读

本篇是「大观园平面复原诸家说」的一次带独立核验的综述。每一家先给可编码的事实(园门朝向 / 尺度 / 水系格局 / 景点相对方位),再附**核验状态**——由另一路核验者独立 fetch 原始网页、下载原图放大判读后给出的裁决。

核验状态取法(与 verdicts 字段的映射):

| 状态 | 取法 | 本篇处理 |
|---|---|---|
| **通过** | `refuted=false` 且 `severity=ok` 或 `unverifiable` | 直接采信;`unverifiable` 另行注明「书目立场可核、直接引文未落到原始文本」 |

**核验者原话**

1. **先立硬约束**:十八回「东面飞楼曰缀锦阁,西面斜楼曰含芳阁」、十七回水路七段、三十八/四十/四十九/七十六回围绕藕香榭的四条咬合关系——这些是无争议的裁判条款,应先编码为不可违约束。
2. **主干取徐恭时**(85 编号最完备、方位最可判读),但必须打上本篇的两条更正(缀锦阁 / 含芳阁对调、「已未」→「己未」),并把 15/16/17/22 之外的杨乃济编号一律视作参考。
3. **东西向的两大歧点(D3 潇湘 / 怡红、D5 稻香村)属设计选择,不是考据结论**——纸上诸家与实建两园正好相反,任选一侧都要在文档里显式声明立场,不要伪装成定论。
4. **实建两园(北京 / 上海)只作施工与体量参照,不作方位权威**;其潇湘东 / 怡红西是少数派做法。
