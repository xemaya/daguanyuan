## 0 本篇怎么用

前三篇是**取证**:01 收各家复原方案,02 收原文空间证据,03 收尺度/水系/规模。三篇都做了独立核验,但都**刻意不做判决**——凡冲突处一律并列存档。本篇是**判决书**:把所有还在打架的地方一次裁完,给出建模时唯一采用的那个答案。

下游(平面图 → scene.json → 装配器)只读本篇的「裁决」列。01/02/03 是它的脚注。

### 0.1 裁决优先级(四级,严格自上而下)

| 级 | 依据 | 判据 | 可否被下级推翻 |
|---|---|---|---|
| **L1** | **原文明确陈述** | 《红楼梦》正文里直接说出的空间事实(方位词、邻接、序列、尺寸),非推论 | 否 |
| **L2** | **多家复原共识** | 三家以上独立复原方案指向同一答案,且不与任何 L1 冲突 | 仅被 L1 推翻 |
| **L3** | **单家方案** | 只有一家主张,但论证可核、不与 L1/L2 冲突 | 被 L1/L2 推翻 |
| **L4** | **推测** | 原文与诸家皆无定说,由本项目按自洽与可玩性选定 | 随时可改 |

**L1 内部再分层**(本篇裁 C-01 时用到):**完整连续的叙述** > **举例式罗列**。第十七回游线是「一路走一路说」的连续行文,第十八回「先从有凤来仪、红香绿玉……**等处**」自己声明是举例,故前者压后者。

### 0.2 两条元规则

1. **原文与原文对撞时,不允许用 L1 强行压 L1**——降级到 L2 裁,并把被牺牲的那条原文关系**显式记入代价栏**,不许假装它不存在。本篇有 1 处(C-04 稻香村)。
2. **裁决可以「调和」而非「二选一」**,但调和方案本身必须落在某一级上。例如 C-02 用「环线路程 ≠ 直线距离」同时满足两处原文,该调和归 L1;C-05 用「东北角即北墙的拐角」同时满足两句原文,亦归 L1。凭空发明的调和归 L4。

## 一、原文内部矛盾(13 条)

### C-01 怡红院的位序:十七回末站 vs 十八回第二站

**争点**
- 十七回游线:潇湘馆 → 稻香村 → 蓼汀花溆 → 蘅芜苑 → 正殿/牌坊 → 沁芳闸 → **怡红院(末站)** → 出园。02 篇实测字符位序坐实(牌坊 6207 → 十之五六 6497 → 沁芳闸 6630 → 怡红院 6766 → 大山阻路 7880)。
- 十八回:「進園來先從『有鳳來儀』,『紅香綠玉』,『杏帘在望』,『蘅芷清芬』**等處**,登樓步閣,涉水緣山」——**怡红院(红香绿玉)排第二**。

**裁决 [L1]**:**取十七回,怡红院为末站(东南近门区)**。第十八回那串不作行次使用。

**理由**:两者同为原文,但性质不同。十七回是连续行文,每两站之间都有交通句(「出亭过池」「倏尔青山斜阻,转过山怀中」「转过山坡……盘旋曲折」「度过桥去」「行不多远」「引客行来」),是一条**可走的路径**;十八回那句以「等处」收尾,自陈为举例枚举,且四个名字恰是元春当晚题额四首诗的次序(有凤来仪/红香绿玉/杏帘在望/蘅芷清芬),是**题咏名单**而非行走顺序。按 0.1 的 L1 内部分层,连续叙述压举例罗列。

**代价**:无。十八回该句在建模中只用作「元妃步行游幸确曾到过这四处」的存在性证据。

### C-02 正殿群离园门到底多远:「十之五六」 vs 四十回的即到即达

**争点**
- 十七回到沁芳闸时贾政一行「才游了十之五六」,而正殿/牌坊就在闸之前 → 正殿在园之**深处**。
- 四十回贾母清早进园,「說笑之間,已來至沁芳亭子上」;同回李纨一早就在**大观楼下**开缀锦阁搬桌子,贾母进来她迎上去 → 大观楼似乎**离园门不远**。
- 连锁放大(02 篇待裁决冲突第 3 条):嘉荫堂在园正门近处(七十五回),凸碧山庄在嘉荫堂旁山脊,凹晶在山下池沿「直通着那边藕香榭的路径」,藕香榭又与缀锦阁「隔水相近」——一条链把大观楼群整个拽向园门。

**裁决 [L1]**:**大观楼群置于全园北端中轴;「十之五六」指环线已行的路程比例,不指与园门的直线距离**。四十回的即到即达则由「园门—沁芳亭—大观楼」这条**直线短、但游线绕行长**的几何同时满足。

**理由**:十七回开篇贾政自己定了走法——「我們就從此小徑游去,**回來由那一邊出去**,方可遍覽」,这是明写的**环线**,不是往返。环线上「走完五六成」与「离起点很远」在几何上根本不是一回事:绕园一周走到北端时正好过半,而北端到南门的直线距离可以很短。四十回李纨在大观楼下迎驾、贾母说笑间即至沁芳亭,走的是南北向的**直线捷径**(同回明写凤姐等人「**抄著近路**到了秋爽斋」,原文自己承认园内有近路)。故二者无须择一。

至于凸碧—凹晶—藕香榭—缀锦阁那条链:它只证明**东部院落群与大观楼隔水相望**,并不要求大观楼靠近园门;嘉荫堂近正门是园之**东南**近门,凸碧山自东南向北隆起,山脚池沿北通藕香榭——链条走的是园的东侧,不穿中轴。

**代价**:无。反而给出一条建模硬要求见 §3 第 4 条。

### C-03 沁芳闸的水向:引泉而入 vs 流出沁芳闸

**争点**
- 十七回(宝玉答贾政):「原來這橋便是**通外河之閘,引泉而入者**」「此乃**沁芳泉之正源**,就名『沁芳闸』」——进水。
- 二十三回:落花「浮在水面,飄飄蕩蕩,**竟流出沁芳闸去了**」;黛玉接着说「**只一流出去**,有人家的地方臟的臭的混倒」——出水。

**裁决 [L1]**:**全园只设一座沁芳闸,在东北,职能为进水口**。二十三回的「流出沁芳闸」记为作者以「沁芳」泛称全水系的顺笔,不据此增设第二座闸;水的实际出园点另在怡红院后墙下(见 S-07)。

**理由**:十七回那段是**定义性问答**——贾政问「此闸何名」,宝玉答其名与其性质,原文把「通外河」「引泉而入」「正源」三个属性一次说尽,是全书对该建筑最正式的一次界定。二十三回是叙事顺笔,写花瓣漂走,「沁芳」在该回同时用作闸名、桥名与水名(「沁芳闸桥边桃花底下」),泛称成立。以定义压顺笔。

**代价(记账)**:二十三回「花瓣流出沁芳闸」在模型里**字面不可实现**——落于沁芳亭池的花瓣会向西南漂向出水口,不会漂回东北的闸。若日后要做黛玉葬花的场景演出,须把该处水面事件锚在出水口一侧,或接受与原文字面的偏离。

### C-04 稻香村的两组邻接:紧接潇湘馆 vs 紧邻暖香坞 ★最尖锐

**争点**(这是全书最硬的一处空间打结)
- 十七回:潇湘馆出来「**倏爾青山斜阻。轉過山怀中**」即稻香村 → 稻香村与潇湘馆之间只隔一座山。
- 七十四回:凤姐抄检「往**對過暖香塢**來。彼時李紈猶病在床上,他與**惜春是緊鄰**,又與**探春相近**,故順路先到這兩處」 → 稻香村紧邻暖香坞、又近秋爽斋。
- 而暖香坞由五十回锁死在藕香榭之东(「過了藕香榭,穿入一條夾道,東西兩邊皆有過街門……如今進的是**西門**」),藕香榭又由十八回「東面飛樓曰綴錦閣」+ 四十回「藕香榭……隔水相近缀锦阁」锁死在中轴以东。
- 结论:潇湘馆若在西,稻香村跟着在西;暖香坞在东,稻香村又得跟着在东。**两条都是原文明确陈述,直接对撞。**

**诸家怎么处理**:徐恭时(25)、杨乃济(7)、曾保泉、葛真一致把稻香村放**西**;徐建平 2023 与北京大观园放**东**。葛真是唯一把这个矛盾摊开写的人:「權衡得失,我們只好**暫時舍棄村、塢的緊鄰關系**,仍置村于園子西側。」

**裁决 [L2 · 原文互撞降级]**:**稻香村置于园西/西北(潇湘馆之北,隔青山)**,与葛真、徐恭时、杨乃济、曾保泉四家共识一致。

**理由**:按元规则 1,两条 L1 对撞时不得以 L1 压 L1,降级到 L2 裁。西侧一方有四家独立复原共识,东侧一方只有徐建平一家纸上方案 + 北京实建园(而实建园按 §S-03 已判定为方位上的少数派,不作权威)。更实质的是:十七回那条邻接**自带交通描写与地形**(青山斜阻、山怀、篱外山坡土井、分畦列亩),是可直接落成地形的;七十四回那条只是抄检夜里的**顺路陈述**,不含地形信息。同等级别下,取信息量大、可落地的一条。

**代价(记账)**:七十四回「李纨与惜春紧邻、与探春相近」在模型中**降为路径相邻而非物理相邻**——凤姐从秋爽斋往暖香坞、再折向稻香村,走的是绕池的一段路而不是隔墙。这是自葛真起就公开承认的坏账,本项目继承之,不假装解决。若日后要演抄检夜的连续行走镜头,须接受这一段路程被拉长。

### C-05 水源方位:「北拐角墙下」 vs 「东北山坳」

**争点**
- 十六回:「會芳園本是從**北拐角牆下**引來一股活水,今亦無煩再引。」
- 十七回贾珍:「原從那閘起流至那洞口,從**東北山坳**里引到那村庄里……」;闸为「通外河之闸,引泉而入者」。
- 表面上一说「北」,一说「东北」;且 02 篇注 E03 已警告:十六回讲的是**会芳园旧有**水源,不得径直等同于沁芳闸。

**裁决 [L1 · 调和]**:**进水口设于园之东北角,即北墙的东端拐角处**;沁芳闸即该处水口的闸桥,沿用会芳园旧水口而非新凿。

**理由**:「北拐角墙下」这个说法本身就指**北墙的拐角**,而园的东北角正是北墙的一个拐角——两句话在东北角上是重合的,不必二选一。十六回「今亦无烦再引」明说沿用旧源,故旧水口与沁芳闸同址不但不冲突,反而是原文暗示的省工做法。诸家亦向东北收敛:武迪「水源在园区的东北角上,也就是沁芳闸的所在」、徐建平「闸在东北一隅」、童力群「沁芳闸是位于大观园东北角的引水闸」——L2 与 L1 同向。

**代价**:无。

### C-06 「大山」的身份:翠嶂,还是大主山

**争点**:十七回结尾出园「忽見**大山阻路**……直由山腳邊忽一轉,便是平坦寬闊大路,豁然大門前見」。这座山是门内那座翠嶂,还是园北的大主山?原文未说。02 篇注 E26 明确判定「(即翠嶂)」是研究者替原文做的身份指认,不得当原文写;03 篇核验者同样指出「首尾呼应」是读法而非原文。

**裁决 [L4 · 推测]**:**判为翠嶂**。翠嶂做成东西向的一带长山,西端(入园小径口)与东端(出园绕行处)分居正门两侧,山脚一转即豁然见门。

**理由**:纯属本项目的自洽选择,不是考据结论。取翠嶂的三点好处:(1) 原文「直由山脚边忽一转,便是……豁然大门前见」要求此山**紧贴大门**,而大主山在北端统领蘅芜苑与凸碧一带,拉到门前会与十七回「那大主山所分之脉,皆穿墙而过(蘅芜苑)」矛盾;(2) 「一带翠嶂」的「一带」本就是横长形,做成长山无须新增假设;(3) 省一座山,并让入口障景与出口障景是同一体量,游线首尾闭合更可读。

**建模落点**:翠嶂长约 120–160 m、高 8–12 m 的东西向石山,正门在其南,山体两端各留一口:西口入(镜面白石题「曲径通幽处」),东口出(接平坦宽阔大路)。**此条标为推测级,可在平面图阶段被推翻。**

### C-07 「三里半大」的读法

**争点**:周长说 / 两边长之和说 / 面积说。三种读法推出的园子面积差数倍。02 篇注 E01 已把 confidence 降为 medium 并要求「当可调参数而非硬约束」;03 篇核验者进一步驳掉了「学界主流取周长义」的无出处断言,可核到取周长义者只有润杨(自媒体),而胡铁岩按晚清里亩换算得「五亩多一点」并明确反对。

**裁决 [L2 · 声明为可调参数]**:**取周长义 + 营造尺库平制(1 尺 = 0.32 m,1 里 = 576 m)→ 周长 2016 m → 主画布 500 m × 500 m = 25 ha**,园界为落在该包围盒内的不规则折线墙,净面积 20–25 ha。承 03 篇 §1.4,不重开。

**理由**:两条互相独立的路线在同一量级会合——原文路线 2016 m 周长 → 等价方形边长 504 m;复原图路线童力群 372 亩 = 24.8 ha → 等价方形边长 498 m,相差 1.2%。会合本身即是取周长义的最强旁证。胡铁岩的 5–6 亩说与全书描写(数十处院落、可行两只棠木舫的大池、山脊敞厅、百余步上山)不相容,不采,仅存为争议边界。尺值必须显式声明:采营造尺 0.32 m,与 `docs/fashi` 材分制推导器同源,**不引 644.6 m/里说**。

**代价**:无,但**此数是可调参数**:若布局阶段发现 500 m 见方容不下或过空,允许在 437–564 m(即市里说与 644.6 m 说的两端)之间调整,拓扑不受影响。

### C-08 惜春一人三名:蓼风轩 / 藕香榭 / 暖香坞,且藕香榭又是公共水亭

**争点**
- 二十三回:「惜春住了**蓼風軒**」;三十七回:「四丫頭在**藕香榭**」;五十回:惜春卧房「門斗上有『**暖香塢**』三個字」。
- 同时,三十八回藕香榭是全体开螃蟹宴的**池中水亭**(「蓋在池中,四面有窗,左右有曲廊可通,亦是跨水接岸,後面又有曲折竹橋暗接」),四十回贾母也点名「就鋪排在藕香榭的水亭子上」——一处私人卧房不可能同时是公共宴集地。

**裁决 [L1]**:**三名同指一组建筑群,不得各画一处**。空间实现为:池中水榭(藕香榭本体,公共)→ 曲廊/竹桥接岸 → 岸上过藕香榭穿东西夹道(西门额「穿云」/「度月」,东门通宝琴立雪的山坡)→ 夹道中段向南的正门 → 院内游廊 → 惜春卧房(暖香坞)。「蓼风轩」为该院落群的总名/轩名。

**理由**:三个名字全是原文明写,不存在取舍空间,唯一自洽解就是当一组建筑群。五十回原文本身给出了从藕香榭走到暖香坞的**完整交通描写**(过藕香榭 → 穿夹道 → 进向南的正门 → 游廊 → 卧房),等于原文自己把三名串在了一条路径上。03 篇核验者已把这条列为建模硬约束。

**副产物**:五十回「進了向南的正門」说明该院主体在夹道**之北**;贾母一行是「出了夾道**東門**」才见宝琴立雪山坡,故夹道东西向、东端接山坡。

### C-09 水面尺度自相矛盾:大池 vs 七八尺溪 vs 尺许沟

**争点**:同一条「沁芳」水系,原文给了三档差两个数量级的宽度。
- 四十回:池中可撑两只棠木舫,舟行荇叶渚 → 花溆萝港 → 蘅芜苑岸下,园内另有**船坞**;十七回采莲船四只、座船一只。→ 大池。
- 四十一回:刘姥姥从怡红院后路进,「迎面忽有一帶水池,**只有七八尺寬**,石頭砌岸……上面有一塊白石橫架在上面」。→ 约 2.5 m 的溪。
- 十七回潇湘馆:「後院牆下忽開一隙,得泉一派,**開溝僅尺許**,灌入牆內」。→ 0.3 m 的渠。

**裁决 [L1]**:**不是矛盾,是同一水系的三级分化,全部照实建**。分级如下:

| 级 | 宽度 | 落点 | 通航 |
|---|---|---|---|
| 主池(可行舟) | 40–80 m | 荇叶渚—紫菱洲蓼溆—花溆萝港—蘅芜苑岸;藕香榭—凹晶—芦雪广一带 | 棠木舫/采莲船 |
| 干溪(沁芳溪) | 8–15 m | 沁芳闸 → 蓼汀花溆港洞 → 沁芳亭桥三港 → 怡红院后 | 仅港洞段可通小舟 |
| 支渠 | 0.3–2.5 m | 潇湘馆穿院引泉沟(尺许);怡红院后路一侧七八尺水池(白石板桥) | 否 |

**理由**:三处原文都带具体尺寸或具体行为,没有一处可以被否掉;而一条真实水系本来就上游窄下游宽、干流宽支流窄。02 篇注 E12 已订正潇湘馆是**一道**穿院水沟(非两侧临水),注 E53 已订正七八尺那道水在怡红院**后路一侧**、与后院青溪是同一道水——两条订正正好把最细的两级安置妥当。

### C-10 门内无通视 vs 出园有平坦宽阔大路(中央辇道之争的原文根据)

**争点**(此条同时是 S-02 的原文裁判)
- 十七回入园:「迎面一帶翠嶂擋在前面……**非此一山,一進來園中所有之景悉入目中,則有何趣**」——贾政亲口否定了门内的通视轴线。
- 十七回出园:「直由山腳邊忽一轉,便是**平坦寬闊大路**,豁然大門前見」——园内确有宽路,且**紧贴大门**。

**裁决 [L1 · 调和]**:**有大路,无贯通中轴**。具体:
1. 正门内**不设**直抵正殿的辇道,翠嶂全遮;
2. **近门段设平坦宽阔大路**,自翠嶂东侧山脚绕出直达正门(即出园那条),兼作车马与工役通道;
3. 该大路过沁芳亭桥后**分东西两路**环行全园(曾/顾「有大路,而分东西」);
4. 正殿区自设南向短甬路:玉石牌坊 → 正殿 → 大观楼,长度以院落尺度计(百米级),**不与园门相连**。

**理由**:两句都是原文明写,且指的根本不是同一段路——一句讲门内视线,一句讲门旁路面,可以并存。省亲仪制的顾虑亦不成立:十八回元妃是「上輿進園 → 下輿登舟 → 舟臨內岸,复棄舟上輿」三段换乘,**全程没有走过一条从园门直通正殿的辇道**,原文自己否掉了辇道的必要性。

### C-11 秋爽斋是否临街

**争点**:四十回贾母在秋爽斋听见鼓乐,说「是誰家娶親呢?這里**臨街倒近**」——但下一句王夫人即答「**街上的那里聽的見**,這是咱們的那十幾個女孩子們演習吹打呢」。

**裁决 [L1]**:**秋爽斋不临街,不靠外墙**。置于园之西南—中部,近紫菱洲/大池,水陆皆可达。

**理由**:原文自带反驳——贾母的猜测在同一段内被王夫人当场否定,这是叙事上的一次纠错,不是空间证据。02 篇注 E47 已判定此条不能当「秋爽斋近街」的正面证据,并删去了外加的「梨香院」。真正可用的定位证据是四十回「便向紫菱洲蓼漵一帶走來……鳳姐……**抄著近路到了秋爽齋**」(近池、有近路可通)与七十四回「凤姐……往**對過**暖香坞来」(与暖香坞隔水相对)。

### C-12 花冢在哪

**争点**
- 二十三回:宝玉在「沁芳閘橋邊桃花底下」葬花,黛玉说「**那畸角上**我有一個花冢」——「那」是远指。
- 二十七回:宝玉自怡红院去花冢要「**登山渡水,過樹穿花**」,且「將已到了花冢,**猶未轉過山坡**」。

**裁决 [L1]**:**花冢在园之偏僻畸角(取东北,近沁芳闸外侧的墙角坡地),自怡红院去需登山渡水、隔一道山坡**。不置于沁芳闸桥头。

**理由**:02 篇注 E35 已订正——黛玉用的是远指「那畸角上」,二十三回只说明二人当时**在闸桥边**,没说花冢在闸桥边。二十七回的交通描写(登山渡水、过树穿花、转过山坡)才是距离陈述,明确指向一处需要跋涉的角落。取东北是因为童力群独立判断「沁芳闸……花冢在此」(L3,与 L1 不冲突,采为落点)。

### C-13 园址三句能否自洽:东边起 / 转至北边 / 仪门往东 / 便门通宁府

**争点**(表面冲突,常被当矛盾引用)
- 十六回:「從**東邊**一帶,借著東府里花園起,**轉至北邊**,一共丈量准了,三里半大」;又「先令匠人拆宁府會芳園牆垣樓閣,直接入榮府**東大院**中」。
- 十八回:元妃版舆「抬進大門,入儀門**往東去**」到体仁沐德更衣,更衣毕「上輿進園」。
- 一〇二回:尤氏「從前年在園里開通宁府的那個**便門**里走過去了」。

**裁决 [L1 · 调和]**:**四句自洽,无需裁决,直接联立**:大观园占荣国府之东、宁国府之西北,由荣府东大院 + 宁府会芳园合并而成,平面自西南向东北铺开;**园正门开在南墙偏东**;园东墙有便门通宁府;园与荣府另有西墙角门相通(徐恭时 33/34 通王夫人房、贾母房)。

**理由**:「从东边一带起,转至北边」描述的是**丈量的走向**(自荣府东侧起,折向北),不是园门方位;十八回「入仪门往东去」讲的是元妃在**荣府院内**的行进方向,恰好把园门定在荣府之东。三句拼起来只指向一个解。

**副产物(建模用)**:荣府在园之西南、宁府在园之东南/东,园门南开偏东,与诸家「南门」共识一致(S-13)。

## 二、诸家复原方案的分歧(15 条)

> 每条格式:**争点 → 各家站位 → 裁决(级) → 理由 → 代价**。诸家站位据 01 篇,已按其核验 correction 修正(徐恭时缀锦阁/含芳阁已对调,戴志昂「西北外突」已删)。

### S-01 中心大湖有无

- **有**:戴志昂鸟瞰图 + 1963 模型(曾/顾:「以颐和园昆明湖为蓝本」);上海大观园。
- **无**:曾保泉/顾平旦、徐恭时(专节「大观园中间是一个大湖吗?」)、黄葆芳、武迪(「以河流为主的,而非大片开阔水域」)。
- **中间态**:杨乃济图、北京大观园(中央有池,非大湖)。

**裁决 [L1]**:**无中央大湖**。水系骨架是一条有源、有岔、有出口的**溪**,沿溪张开三处池面(南池 / 中池 / 东池),不做贯通全园的湖。

**理由**:十七回贾珍那段是全书唯一一条完整水系陈述,拓扑是**线状五段**(闸 → 洞口 → 东北山坳 → 村庄 → 岔口引到西南 → 合流 → 墙下出去),线状水系不可能读成中央大湖。03 篇核验者驳倒的「元妃登舟证明水路直达正殿」是大湖说最后的支撑——实为舆→舟→舆三段换乘,**船段只是中间一截**,既没从园门上船,也没开到正殿前。L1 直接压死 L2/L3。

### S-03 潇湘馆东西 / 怡红院东南 vs 西南

- **潇湘西、怡红东南**:徐恭时图、杨乃济图、曾保泉图、黄云皓图、徐建平、武迪(归纳为「东南角派」)。
- **潇湘东、怡红西**:北京大观园、上海大观园(两座实建园)。

**裁决 [L2]**:**潇湘馆在西(近沁芳亭桥西北),怡红院在东南(近正门)**。

**理由**:原文无一句直接方位,L1 缺席,降到 L2 判。纸上诸家六家一致向西,实建两园是少数派——且实建园的取向掺入了游览动线与建园用地的现实约束,不作方位权威(01 篇建议 4)。此外东部院落群已被 L1 锁死(S-11:藕香榭在东 → 暖香坞/芦雪广/凹晶/凸碧在东;C-13:园门南偏东;七十五回嘉荫堂近正门 → 东南),怡红院取东南可与栊翠庵「顺着山脚刚转过去」的极近关系(四十九回)、嘉荫堂近门、凸碧山南麓连成一个自洽的东南区;若把怡红院搬去西南,这一串全要重排。

**声明**:这是**设计立场,不是考据结论**,须在项目 README 与艺术圣经里显式写明,不得伪装成定论。

### S-04 怡红、潇湘二院远近

- **相邻**:「台湾学者」方案(怡红右下,潇湘在其左上)。
- 武迪另提:潇湘馆与秋爽斋「紧挨」。

**裁决 [L1]**:**近而不相邻——隔一池、一桥、一小山**。二者步行距离约 150–250 m,途中经沁芳亭桥或翠烟桥。

**理由**:原文两面都有明文,合起来正好是「隔物相望」。近的一面:二十三回宝玉「我就住怡紅院,咱們兩個又**近**,又都清幽」。隔的一面:二十六回黛玉自潇湘馆往怡红院要「剛到了**沁芳橋**……再往怡紅院來」;二十五回红玉自怡红院往潇湘馆「正走上**翠煙橋**」,桥旁还有山坡高处。要经桥、经坡,就不是贴邻。

### S-07 出水口

- 原著只说「從那牆下出去」,未指方位。
- 中国侨网(爱新觉罗·焘诚)推为「从怡红院向东南墙角下流出去」——一家之言,该文另把紫菱洲放东南(与徐恭时放西北冲突)。
- 徐恭时图、杨乃济图均未标出水口;戴志昂大湖方案无明确进出。诸家皆悬。

**裁决 [L4 · 推测]**:**出水口设在怡红院后院外的南墙近东南角处**,做成墙下涵洞(水关)。

**理由**:原文只给了两条弱线索,不足以支撑 L1。(1) 贾珍说这话时**站在怡红院后院**——「轉過花障,則見青溪前阻……賈珍遙指道:『……共總流到這里,仍舊合在一處,從那牆下出去』」,「那墙」是他手指所及的近墙,故出水口锁在怡红院一侧;(2) 岔流「引到**西南**上」再回合,说明合流点之前水已绕到西南,合流点本身在怡红院后。怡红院既判在东南(S-03),「那墙」最可能是南墙东段。侨网的「东南墙角」与此实为同一区位,可作旁证,但不因此提级。

**代价/置信**:**推测级**。此裁决只影响一处 30 m 见方的水关构件与末段溪流走向,不影响任何院落方位,可随时改。

### S-08 蘅芜苑相对大观楼

**理由**:三家(徐恭时、曾保泉、杨乃济)指西,是唯一的多家共识方向;两座实建园各执一端,不作权威。与 L1 全部相容:十七回蓼汀花溆 → 折带朱栏板桥 → 蘅芜苑 → 「行不多遠」正殿(蘅芜苑在正殿西南、步行数分钟);四十回舟行荇叶渚 → 花溆萝港 → 蘅芜苑岸下,须临主池且岸高(云步石梯);五十九回蘅芜苑 → 柳叶渚柳堤 → 潇湘馆(西行下坡即到潇湘馆一带);二十六回怡红院 → 沁芳亭 → 蜂腰桥 → 蘅芜苑(自东南斜穿而来)。四条路线在「西/西南、临池北岸」这一点上同时成立。

### S-09 紫菱洲 / 缀锦楼(迎春居)

- 西北:徐恭时图 47(萝港之西)、杨乃济图 9(西北角)。

**理由**:两家(徐恭时、杨乃济)指西北,是纸上方案里唯一有重合的一说;实建园与侨网各执一端且互不相容。与 L1 相容:四十回贾母「一徑離了**瀟湘館**。遠遠望見池中一群人在那里撐舡……便向**紫菱洲蓼漵**一帶走來」——出潇湘馆即见,故紫菱洲近潇湘馆;七十九、八十回紫菱洲临大池、岸有蓼苇、池有荇菱。

### S-10 凸碧山庄 / 凹晶溪馆 / 栊翠庵

- 园东:徐恭时(74/75/76)、葛真(凹晶、凸碧、嘉荫堂皆东部;栊翠庵东部近怡红院)、武迪(栊翠庵在藕香榭/凹晶东面)。
- 西北:北京大观园。西侧:上海大观园(栊翠庵)。曾保泉图:栊翠庵在怡红院东南。

**裁决 [L2,且有 L1 支撑]**:**全部置于园之东部**——嘉荫堂在东南近正门,凸碧山庄在其旁山脊(百余步缓坡上),凹晶溪馆在同山低洼近水处,栊翠庵在怡红院东北、山脚转角处。

**理由**:三家纸上方案(徐恭时、葛真、武迪)一致指东,两座实建园各执一端。更强的是 L1 链条,四条原文把这一组彼此焊死:七十五回「賈母且在**嘉蔭堂**中吃茶少歇……方扶著人上山來」+「從下逶迤而上,不過**百餘步**,至山之峰脊上」(嘉荫堂 → 凸碧,百余步);七十六回「這**山坡底下就是池沿**……山之低洼近水處,就叫作凹晶」+「只一轉彎,就是池沿,沿上一帶竹欄相接,**直通著那邊藕香榭的路徑**」(凸碧 → 凹晶 → 池沿 → 藕香榭);四十九回「走至山坡之下,**順著山腳剛轉過去**」即见栊翠庵红梅(怡红院 → 栊翠庵,极近)。藕香榭已由 S-11 判在东,整链随之在东。

### S-11 藕香榭东 vs 西(S-10 的上游总闸)

- 东岸:葛真(并由此推出暖香坞/芦雪庵/凹晶/凸碧/嘉荫堂全在东部)。中轴以东池中:北京大观园。
- 西面:戴志昂《红楼梦大观园的园林艺术》——被葛真点名批评「是可疑的」。

**裁决 [L1]**:**藕香榭在中轴以东,池中**。全园东部院落群的定位锚。

**理由**:这是全篇唯一一条能被原文**直接算出来**的方位。链子三步:(1) 十八回「**東面**飛樓曰『綴錦閣』,西面斜樓曰『含芳閣』」——缀锦阁在大观楼东,这是全书判定东西向的唯一硬标尺;(2) 四十回贾母「就鋪排在**藕香榭**的水亭子上,借著水音更好聽。回來咱們就在**綴錦閣底下**吃酒,又寬闊,**又聽的近**」——藕香榭与缀锦阁隔水相近,近到乐声可闻;(3) 故藕香榭必在大观楼东侧水面上。戴志昂的「藕香榭在园的西面」与十八回硬标尺直接相反,弃。葛真由此推出的东部院落群(L3)因与 L1 同向而全部采纳。

**裁决 [L2]**:**500 m × 500 m 包围盒,净地 20–25 ha**,同 C-07。

### S-13 园基形状与园门位置

- 西北角外突:徐恭时图(戴志昂原被列入此说,已被 01 篇核验驳倒——戴图园基实为规整平行四边形)。
- 方形东南缺角、后门在北墙近西北角:曾保泉图(据刘孝存转述)。
- 规则长方形、南门偏东:杨乃济图、北京大观园。

**裁决 [L2]**:**长方形包围盒 + 不规则折线围墙**;**正门在南墙偏东**;北墙东段设后门;东墙设便门通宁府;西墙设两处角门通荣府(王夫人房、贾母房方向);西南角设聚锦门。

**理由**:形状上,三里半若为周长,任何周长 2016 m 的闭合形都合规,故取「长方形包围盒 + 折线墙」——既服从杨乃济/北京园的长方形共识,又给徐恭时的外突与曾保泉的缺角留了实现余地(折线墙可局部内凹外凸),不必在三家间硬选。门位上有 L1 支撑:十八回「入儀門**往東去**」定园门在荣府之东(C-13);一〇二回便门通宁府定东墙(02 篇通过);四十一回袭人「再往**西南**上去,若繞出去還好」+ 五十六回「吳大娘和單大娘他兩個在**西南角上聚錦門**等著呢」两句坐实西南角确有一门。

### S-14 原型 / 性质之争(恭王府 / 随园 / 圆明园 / 江宁织造署 / 西溪)

- 周汝昌主恭王府(帝城西);曾/顾把诸说归为艺术典型、综合园林、环境素材三类。
- 反证:恭王府前身为和珅私邸,营建不早于乾隆四十一年,晚于曹雪芹卒年(1763)。周汝昌本人也无独立园图,01 篇核验判定其不宜作可编码的方位方案,且「潇湘馆在恭王府园东部垂花门内」是二手推二手,已被剔除。

**裁决 [L1]**:**不采任何实地原型,按文本自足营造**。恭王府/随园等只作形制与体量的参考素材,不作方位依据。

**理由**:文本层面原文自己回避指实——十八回宝钗写「芳園筑向帝城西」,同一组诗里黛玉紧接着写「名園筑何處,仙境別紅塵」,作者刻意两说并陈(02 篇注 E32 已把「帝城西」降为文学修辞,不作方位约束)。年代层面恭王府说的根基有硬伤。合起来,原型之争对本项目的平面无任何可用约束。

### S-15 梨香院在园内何处

- 徐恭时图:43 在**园西北角**,旁有 44 通后街门。
- 曾保泉:在**南大门内东侧**。徐建平:近沁芳闸(东北)。
- 三家两两不相容,且徐恭时与徐建平的组合直接制造了 S-06 的内部矛盾。

**裁决 [L1]**:**梨香院不在大观园内**,置于荣府东北角、园之西南墙外,作为外部参照物建模(可远观,不入游线)。

**理由**:第四回原文把梨香院明确交代为荣国府内的一所独立小院——荣公暮年养静之所,十余间房屋前厅后舍俱全,**另有一门通街**,西南角门通夹道、出夹道即王夫人正房之东。它是薛家借住处、后为女伶教习处,与大观园的营建(十六回)无关,三家把它画进园里缺原文依据。

**⚠︎ 待校**:第四回原文本轮**未经 02 篇的逐字核验流程**(02 篇已查回目为 016/017/018/023/025/026/027/035/037/038/040/041/049/050/056/059/062/070/074/075/076/079/080/102,不含 004)。本条裁决方向可用,但引用第四回文字前须回 zh.wikisource 第 004 回逐字核校,尤其「东北角」字样。

## 四、裁决联立后的平面拓扑(给下一步:平面图)

把 28 条裁决联立,得到唯一一个不违 L1 的分区骨架:

```
                    ┌──────── 北墙 ────────┐
        大主山       │            [后门]     │
  ┌─────────────────┴──────────┐  ◆沁芳闸(进水)  ← 外河
  │  蘅芜苑   正殿·大观楼群      │      ↓
  │  (西南倚山) 含芳阁|缀锦阁    │   蓼汀花溆港洞
  │            省亲别墅牌坊      │      ↓
  │                              │   ┌ 主池(东北段) ┐

  香   荇叶渚·蓼溆              │   └ 暖香坞(夹道东) ┘
  村                            │
  (西北) 秋爽斋       ← 对过 →   │   凹晶溪馆
  │        潇湘馆              │   凸碧山庄(山脊)
  │  翠烟桥  沁芳亭桥(三港)      │   嘉荫堂  栊翠庵
  │   滴翠亭    ↓南池           │      怡红院(东南)
  └───[聚锦门·西南]──翠嶂(一带长山)──┴─ 出水口·墙下涵洞
                    ▲正门(南墙偏东)     [东墙便门→宁府]
```

**七条不可违约束**(编码为断言,任何布局调整都要复检):

1. **缀锦阁在大观楼东、含芳阁在西**(十八回,唯一东西向硬标尺)。
2. **藕香榭在中轴以东、池中**,且与缀锦阁隔水可闻乐(十八 + 四十回)。
3. **凸碧(山脊)—凹晶(山下近水)—池沿竹栏—藕香榭** 四点连通,且嘉荫堂到凸碧上山**不超过百余步缓坡宽路**(七十五、七十六回)。
4. **水系是线状五段**:外河 → 沁芳闸(东北)→ 洞口 → 东北山坳 → 稻香村 →〔岔口 → 西南〕→ 怡红院后合流 → 墙下出园(十七回,唯一完整水系陈述)。
5. **翠嶂全遮门内视线**,正门内不得看见任何院落或正殿(十七回贾政语)。
6. **十七回 29 节点游线必须能连续走通**,且为环线(小径入 / 另一边出),游至正殿时累计路程 ≈ 全程 55%(可作 harness 断言:`path_ratio_at_main_hall ∈ [0.50, 0.62]`)。
7. **暖香坞正门朝南**,其北为夹道,夹道东西向、西门额「穿云/度月」、东门外接山坡(五十回)。
