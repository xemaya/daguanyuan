# 07 《红楼梦》建筑原文摘录

日期:2026-09-10 | 章 id:`07-honglou` | 规则 74 条:通过 69 / 存疑 5 / 驳倒 0

## 本章在推导链里的位置

本项目的优先级栈是 **原文 > 清式 > 法式 > 江南**,《红楼梦》原文是第一真源,本章就是这一层的地基。本章**只做逐字摘录与属性编码,不做形制推导**:把第三、七、十一、十三、十四、十七、十八、二十六、三十五、三十八、四十、四十一、四十九、五十、五十三、六十二、七十五、七十六回中一切描写建筑做法与空间的句子逐字摘出,转写成可直接编码的属性(类型/间数/屋顶/墙体/材质/植物/室内/路径/数量),下游章节(构件库 `src/cn`、法式推导器 `src/fashi`、场景装配器)据此建模。

因此本章的验收标准与《营造法式》诸章不同:**规则的对错首先是"是不是原文这么写的"**,其次才是"这个做法在清代/江南实物上成不成立"。凡原文与实物冲突者(如园门五间 vs 荣府三间兽头大门),原文优先,但必须在核验状态里标出张力,禁止下游拿小说数值反推清代规制。

核验方式:每条规则两名反驳者。甲核对原文(维基文库《紅樓夢》逐回逐字比对,含引文删节、说话人、上下文归属、版本异文);乙核对实物与内部一致性(清代/江南园林实测、跨回自洽、计数与折算)。二人均未驳倒记**通过**(附 imprecise/unverifiable 备注);一人驳倒记**存疑**(两人原话与 correction 全抄,读者自判);二人均驳倒记**驳倒**,入章末"已否决"。

底本说明:全部引文取自维基文库《紅樓夢》(https://zh.wikisource.org/wiki/紅樓夢 ,页面自注"前八十回以庚辰本為底本,後四十回以程甲本為底本")。ctext.org 对自动抓取返回反爬页,程甲本对照未完成。乙在 07-08 / 07-65 指出该本实为逐回附异文注的**汇校本**而非纯庚辰底本,见 open_questions。

## 通过

### 07-01 大观园正门

- **现代表述**:大观园正门五开间,筒(桶)瓦泥鳅脊;门栏窗槅细雕花样、不施朱粉;墙体一色水磨群墙;白石台基,雕西番草纹。
- **公式与参数**:`gate = {bays:5, roof_tile:'桶瓦', ridge:'泥鰍脊', joinery:'細雕花樣,無朱粉', wall:'水磨群牆', plinth:'白石台磯,西番草紋'}`;bays=5 間;roof=桶瓦泥鰍脊;wall=水磨群牆;plinth=白石台磯,鑿西番草花樣;paint=無朱粉涂飾。
- **原文引文与出处**:第十七回:"只見正門五間,上面桶瓦泥鰍脊,那門欄窗槅,皆是細雕新鮮花樣,并無朱粉涂飾,一色水磨群牆,下面白石台磯,鑿成西番草花樣。"(https://zh.wikisource.org/wiki/紅樓夢/第017回 )
- **核验状态**:**通过**(imprecise)。甲:引文逐字存在,五间/桶瓦泥鳅脊/西番草全对;但 statement 与 formula 曾把"一色水磨群牆"写成"水磨砖群墙","磚"字是本段所无的添字(该字出现在同回蘅芜苑"一色水磨磚牆,清瓦花堵"),parameters 表反而写对,内部不自洽——**甲的更正:statement/formula 应作"一色水磨群墙",不加"砖";若要注"砖"应标为注释性推断。已按此更正。** 乙:逐条核对成立,但须提醒**该值不可用作清代门第规制推导**——同书荣国府正门仅"三间兽头大门"(07-53),园门五间反高于府门;颐和园排云殿面阔七间、仁寿殿九间。即园门五间是小说的礼制越格(省亲别墅特例),不是可外推的实测常规。"桶瓦=筒瓦"的通释乙未能独立核到江南屋脊类型表(未查到《营造法原》甘蔗脊/纹头脊/哺鸡脊/雌毛脊序列中泥鳅脊的位置),unverifiable。

### 07-02 大观园外围墙

- **现代表述**:园墙上部雪白粉墙,下部虎皮石墙脚,随地势砌筑。
- **公式与参数**:`garden_wall = {upper:'雪白粉牆', base:'虎皮石', alignment:'隨勢砌去'}`
- **原文引文与出处**:第十七回:"左右一望,皆雪白粉牆,下面虎皮石,隨勢砌去,果然不落富麗俗套,自是歡喜。"(https://zh.wikisource.org/wiki/紅樓夢/第017回 )
- **核验状态**:**通过**。甲:三项参数与原文一致。乙:虎皮石墙脚+上部粉白、随地势砌筑是江南园墙通行做法,与苏州园林粉墙体系一致(https://zh.wikipedia.org/wiki/拙政园 ),无可驳之处。

### 07-03 入门翠嶂(障景假山)

- **现代表述**:进正门迎面一带翠嶂遮挡全园;为白石假山,苔藓藤萝,内藏羊肠小径。
- **公式与参数**:`entry_screen = {type:'假山翠嶂', material:'白石', cover:['苔蘚','藤蘿'], path:'羊腸小徑', function:'障景'}`
- **原文引文与出处**:第十七回:"遂命開門,只見迎面一帶翠嶂擋在前面。……賈政道:'非此一山,一進來園中所有之景悉入目中,則有何趣。'……見白石峻嶒,或如鬼怪,或如猛獸,縱橫拱立,上面苔蘚成斑,藤蘿掩映,其中微露羊腸小徑。"(https://zh.wikisource.org/wiki/紅樓夢/第017回 )
- **核验状态**:**通过**。甲:三段引文均逐字存在(跳跃已用"……"标注);"障景"是对贾政原话的功能概括,formula 已标为 function,未越出原文。乙:障景入口在实物中普遍存在(恭王府萃锦园入口独乐峰即同一手法,https://zh.wikipedia.org/wiki/恭王府 ),可对上。

### 07-04 山口镜面白石留题处

- **现代表述**:山口处山上留一块镜面白石作题字处,题"曲徑通幽處"。
- **公式与参数**:`inscription_stone = {position:'山口迎面', material:'鏡面白石', text:'曲徑通幽處'}`;count=1 塊。
- **原文引文与出处**:第十七回:"抬頭忽見山上有鏡面白石一塊,正是迎面留題處。"同段"莫若直書'曲徑通幽處'這句舊詩在上"。(https://zh.wikisource.org/wiki/紅樓夢/第017回 )
- **核验状态**:**通过**。甲:引文逐字存在;"曲徑通幽處"确为同回宝玉所拟并获众人赞同之题字,数量与原文"白石一塊"一致。乙:数量 1 块无争议。

### 07-05 石洞北面飞楼

- **现代表述**:穿石洞向北平坦宽豁,两侧飞楼插空,雕甍绣槛,半隐于山坳树梢。
- **公式与参数**:`zone_after_cave = {orientation:'北', terrain:'平坦寬豁', buildings:'兩邊飛樓', detail:'雕甍繡檻', concealment:'山坳樹杪'}`
- **原文引文与出处**:第十七回:"再進數步,漸向北邊,平坦寬豁,兩邊飛樓插空,雕甍繡檻,皆隱于山坳樹杪之間。"(https://zh.wikisource.org/wiki/紅樓夢/第017回 )
- **核验状态**:**通过**。甲:上文确为"說著,進入石洞來",故"穿石洞向北"成立。乙:方位记为"北"并注明是相对行进方向,无夸大。

### 07-06 沁芳亭桥

- **现代表述**:白石栏杆环抱池沿;石桥三港(三孔),兽面吐水;桥上建亭,亭压水而成,题"沁芳"。
- **公式与参数**:`bridge = {material:'石', arches:3, rail:'白石', spout:'獸面銜吐', pavilion_on_bridge:true, name:'沁芳'}`
- **原文引文与出处**:第十七回:"俯而視之,則清溪瀉雪,石磴穿云,白石為欄,環抱池沿,石橋三港,獸面銜吐。橋上有亭。……但此亭壓水而成,還須偏于水題方稱。"(https://zh.wikisource.org/wiki/紅樓夢/第017回 )
- **核验状态**:**通过**。甲:两段引文逐字存在;"三港"释为三孔属通行注解,arches:3 未超出原文。乙:有清代实物正面支持——颐和园西堤豳风桥即"桥上有亭"的亭桥,三孔石桥+桥亭是清代园林现成类型,pavilion_on_bridge=true 与 arches=3 都对得上,不构成臆造(https://zh.wikipedia.org/wiki/颐和园 )。

### 07-07 潇湘馆外观

- **现代表述**:粉墙围合,内数楹修舍,千百竿翠竹遮映。

### 07-08 潇湘馆正房与游廊

- **现代表述**:入门即曲折游廊,阶下石子甬路;正房小小两三间,一明两暗;家具依地步打就。
- **公式与参数**:`xiaoxiang_main = {corridor:'曲折游廊', path:'石子漫甬路', bays:'兩三間(小小)', plan:'一明兩暗', furniture:'合著地步打就'}`
- **原文引文与出处**:第十七回:"于是大家進入,只見入門便是曲折游廊,階下石子漫成甬路。上面小小兩三間房舍,一明兩暗,里面都是合著地步打就的床幾椅案。"(https://zh.wikisource.org/wiki/紅樓夢/第017回 )
- **核验状态**:**通过**(imprecise)。甲:引文逐字存在;维基文库首页自述"前八十回以庚辰本為底本",故"庚辰底本作兩三間"可查证,且已诚实标明程本异文未核。乙:正文建筑内容无误,但**版本学表述站不住**——该条把维基文库整本称作"庚辰底本",而同站第五十回校勘注显示其底本在"芦雪广(庚辰)/芦雪庵(戚序、王府)/芦雪亭(梦觉、程甲)/芦雪庐(列藏)"一处印的是"芦雪庵",即戚序/王府读法;所以维基文库红楼梦是校汇本而非纯庚辰底本,"两三间"恰与庚辰相合是巧合性一致,不能拿它反证底本。**乙的更正:source.book 改为"紅樓夢(維基文庫校汇本,逐回附庚辰/戚序/王府/夢覺/程甲/列藏异文注)",并保留"程本作小小三间"为未核项。**(https://zh.wikisource.org/wiki/紅樓夢/第050回 、https://zh.wikisource.org/wiki/紅樓夢/第049回 )

### 07-09 潇湘馆后院与引泉

- **现代表述**:里间小门通后院,植大株梨花与芭蕉;另有两间退步;后院墙下开隙引泉,沟宽仅尺许,绕阶缘屋至前院,盘旋竹下流出。
- **公式与参数**:`xiaoxiang_rear = {door:'里間小門', plants:['梨花','芭蕉'], annex:'兩間小小退步', stream:{width:'尺許', route:'牆下→繞階緣屋→前院→竹下出'}}`;annex_bays=2 間;stream_width=尺許。
- **原文引文与出处**:第十七回:"從里間房內又得一小門,出去則是後院,有大株梨花兼著芭蕉。又有兩間小小退步。後院牆下忽開一隙,得泉一派,開溝僅尺許,灌入牆內,繞階緣屋至前院,盤旋竹下而出。"(https://zh.wikisource.org/wiki/紅樓夢/第017回 )
- **核验状态**:**通过**。甲:数值与路线与原文字面一致。乙:可折算校核——清营造尺 32.3 cm,"尺许"≈0.32 m,是庭院明沟/暗渠的正常宽度量级,与江南园林引泉沟渠尺度不冲突,误差在可接受范围(https://zh.wikipedia.org/wiki/尺_(單位) )。

### 07-10 全园帐幔帘子数量

- **现代表述**:全园幔子 120 架、各种帘子共五类各 200 挂、椅搭桌围床裙桌套每分 1200 件。
- **公式与参数**:`furnishing_count = {幔子:120架(已得80,下欠40), 帘子:200挂, 猩猩氈帘:200挂, 金絲藤紅漆竹帘:200挂, 黑漆竹帘:200挂, 五彩線絡盤花帘:200挂, 椅搭/桌圍/床裙/桌套:1200件/分}`
- **原文引文与出处**:第十七回:"妝蟒繡堆,刻絲彈墨并各色綢綾大小幔子一百二十架,昨日得了八十架,下欠四十架。帘子二百挂,昨日俱得了。外有猩猩氈帘二百挂,金絲藤紅漆竹帘二百挂,黑漆竹帘二百挂,五彩線絡盤花帘二百挂,每樣得了一半,也不過秋天都全了。椅搭,桌圍,床裙,桌套,每分一千二百件,也有了。"(https://zh.wikisource.org/wiki/紅樓夢/第017回 )
- **核验状态**:**通过**。甲:长段引文逐字存在,全部数字与原文一致,无推演。乙:把"帘子二百挂"与四种专名帘并列为五类各 200,与原文句法一致,未重复计数。这是陈设采买账不是营造数据,无实物可比对,但规则本身未作跨界推导(unverifiable)。

### 07-11 稻香村外观

- **现代表述**:黄泥矮墙,墙头覆稻茎;数百株杏花;数楹茅屋;桑榆槿柘编成两溜青篱;篱外山坡下土井配桔槔辘轳;畦田菜花。

- **核验状态**:**通过**。甲:各项皆原文所有,"数百株"与参数"幾百株"不冲突。乙:用"稻香村"作条目名属后设命名(该处在第十七回时贾政拟名杏帘在望),但与第十八回定名"遂将浣葛山庄改为稻香村"一致,不算错(https://zh.wikisource.org/wiki/紅樓夢/第018回 )。

### 07-14 稻香村选址批评(天然论)

### 07-15 花圃序列

- **现代表述**:稻香村至蓼汀花溆之间依次经过荼蘼架、木香棚、牡丹亭、芍药圃、蔷薇院、芭蕉坞。

- **公式与参数**:`festival_lighting = {hall:'廊檐內外+游廊罩棚', lamp_types:['羊角','玻璃','戳紗','料絲','繡','畫','堆','摳','絹','紙'], garden_gate:'大明角燈+兩溜高照', paths:'路燈'}`
- **原文引文与出处**:第五十三回:"廊檐內外及兩邊游廊罩棚,將各色羊角,玻璃,戳紗,料絲,或繡,或畫,或堆,或摳,或絹,或紙諸燈挂滿。" ‖ "大觀園正門上也挑著大明角燈,兩溜高照,各處皆有路燈。"(https://zh.wikisource.org/wiki/紅樓夢/第053回 )
- **核验状态**:**存疑**(乙驳倒,imprecise)。
  - 甲(原文):不驳倒。"两段引文逐字存在;灯类十项(羊角、玻璃、戳纱、料丝、绣、画、堆、抠、绢、纸)与原文一一对应,大明角灯、两溜高照、路灯亦原文。"
  - 乙(实物/一致性):**驳倒**。"引文核对成立,但 parameters 的 lamp_types『10 类』把两种不同维度混计:原文句式是四种材质(羊角、玻璃、戳纱、料丝)＋六个『或』字工艺/材料小句(或绣、或画、或堆、或抠、或绢、或纸)。绣/画/堆/抠是做法不是材质,与羊角/玻璃并列成『10 类』会让下游生成 10 种并列灯型。建筑构件项『游廊罩棚』转写无误。"
  - 乙的更正:lamp_types 拆为 `materials:['羊角','玻璃','戳紗','料絲','絹','紙']` 与 `techniques:['繡','畫','堆','摳']`,不再合计为 10 类。

### 07-72 「桶瓦泥鳅脊」该做成什么样;「细雕新鲜花样」该怎么落

- **现代表述**:正门屋脊的形不能按宫殿高正脊做。「泥鳅脊」的具体做法未核到,但**方向可定**:
  软脊、园林式,不是高脊重吻。隔扇的「细雕新鲜花样」原著没写死具体纹样,可落成
  **格心负责"新鲜"、绦环板与裙板负责"细雕"**的三段分工。「西番草」比「新鲜花样」明确,
  是清代流行的卷曲植物纹样(缠枝、卷叶),该把最显眼的具象雕刻留给白石台基,木作更克制。
- **公式与参数**:`gate_ridge = {form:'软脊(卷棚 或 低圆正脊,二读未定)', not:'高正脊+正吻'}`;
  `geshan = {上:'格心(步步锦/灯笼锦/变体棂花)', 中:'绦环板(浅浮雕)', 下:'裙板(浅浮雕)'}`;
  `xifancao = {motif:'缠枝卷叶', place:'白石台磯'}`
- **原文引文与出处**:
  - 第十七回:「上面**桶瓦泥鰍脊**」「那**門欄窗槅,皆是細雕新鮮花樣**」「下面白石台磯,**鑿成西番草花樣**」
    「果然**不落富麗俗套**」(见 07-01,已核验通过)。
  - 卷棚顶定义:「前后两坡相接处**没有明显外露的正脊**,而是成弧线曲面」「省略了屋顶的大脊」
    「可分为**悬山卷棚、硬山卷棚**」「**多用于园林建筑**以及宫殿中宦官、佣人等所居的边房」
    (https://zh.wikipedia.org/wiki/卷棚顶 ,2026-09-12 取)。
- **核验状态**:**存疑**。分三档,不要混着用:
  1. **方向,内证可定(不靠外部资料)**——原文自己下了判断「**果然不落富麗俗套**」,
     而「富丽俗套」在清代屋顶语汇里正是高正脊加正吻那一套。所以正门的脊必须是软的、园林的。
     **这一条可以直接施工。**
  2. **「泥鳅脊」的具体做法,未核到,两读并存**:(a) 低而圆的**正脊**(泥鳅背之形),
     屋面仍有脊线;(b) 即**卷棚/过堂脊**,根本没有正脊。二者剪影都软,差别在有没有脊线。
     07-01 的乙方核验已记:未能在《营造法原》甘蔗脊/纹头脊/哺鸡脊/雌毛脊序列中查到泥鳅脊的位置。
     **选哪一读要留痕进 `provenance.art`,不许写成「原文如此」。**
  3. **「细雕新鲜花样」的三段分工与「西番草=缠枝卷叶」,是二手判断,甲已核其自洽、乙待核**。
     来源是 2026-09-12 用户转来的 LLM 建议(称引北京市文物局收录的红楼梦建筑研究、故宫隔扇资料、
     澎湃关于西番莲纹的文章),**这些引用本身未经我方独立核验**——按 D-04,单个 agent 的报告
     不当事实用。**采用前须补第二人回原始资料核。** 但它有一条不依赖外部资料也成立:
     原文说「新鮮」,而我们现在正门用的是**万字不到头——最标准的纹样**,与「新鲜」直接相反。
- **下游影响**:
  - `builder/parts/damu/building.ts` 的 `menSpec` 走 `fashi` 参数集,其 `Frame` **没有 `ridgeStyle` 字段**;
    卷棚(`ridgeStyle: 'rolled'`)只在 `fayuan` 参数集里实现(`builder/derive/fayuan/building.ts:69`)。
    要给正门上软脊,得给 fashi 加这个自由度,或把正门改由 fayuan 推导——**后者要先回答
    「一座五间 Tier A 门屋该不该走江南参数集」,注意「泥鳅脊」本身就是江南脊名**。
  - 隔扇现在**只有两段**(`makeGeshan`:下 38% 裙板 + 上花格),裙板是素面 `roundedBox`,**缺绦环板、缺浅浮雕**。
- **一条不要搞错**:**别五间全做满雕**。原文的层级是远看五间、中看灰瓦白墙深色木作、走近才见雕工;
  满雕会让门读成家具展厅,正撞「不落富丽俗套」。
