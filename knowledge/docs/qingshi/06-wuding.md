# 06 屋顶、屋脊与瓦作

日期:2026-09-10 | 章 id:`06-wuding` | 规则 16 条:通过 4 / 存疑 7 / 驳倒 5

## 本章在推导链里的位置

本章是屋面层的终点条款:上游从大木章接过**提栈(举折)**与**戗角做法**,下游产出可直接建模的三组量——(1) **屋顶形制**(庑殿/歇山/悬山/硬山/攒尖/卷棚)与脊的条数、走向;(2) **瓦垄与瓦件排布**(瓦号→垄宽→每垄瓦数→露明长);(3) **脊的叠层与端部构件**(正脊/垂脊/戗脊、吻兽走兽、江南各式脊头)。

对大观园而言,链上真正吃紧的是**南北两套系统的切换**:园内绝大多数厅堂、亭榭走《营造法原》系统(蝴蝶瓦小式屋面 + 哺鸡脊/纹头脊 + 提栈算数),只有省亲别墅、家祠一类才够得上官式大式(筒瓦、大脊吻兽、走兽)。因此本章的参数分两组:`system ∈ {官式, 苏式}` 决定用《工程做法》的号数表还是《营造法原》的营造尺(1 尺=275mm),`grade` 决定瓦色与脊型。

核验方式与 01 章一致:每条规则两名核验者独立核验(甲偏原文逐字比对,乙偏实物/实测与旁证)。二人均未驳倒记**通过**;一人驳倒记**存疑**,两人原话与更正值全抄,供自判;二人均驳倒记**驳倒**,移入章末"已否决"并给更正值。

> 口径提示:本章条目按上述"两人都驳倒即驳倒"的规则重排,与上游打包的 kept/contested/dropped 三桶不完全一致——06-14、06-15、06-16 在上游放在 contested,但两名核验者都给了 refuted,按本章口径落入"已否决"。

### 06-05 大式垂脊分段与垂兽/走兽位置

- **现代表述**:垂脊按每坡之长分为三分:上二分为垂脊(兽后段,瓦条二层、混砖、通脊板、混砖、扣脊筒瓦,兽座方砖凿做,垂兽一只、兽角一对);下一分为岔脊(兽前段,瓦条一层、混砖一层,上安狮马五件或七件,圭角一件)。歇山四条戗脊与四条垂脊呈 45° 相交,戗兽在戗脊与垂脊交处;套兽套在角梁头。
- **公式与参数**:`L_垂脊(兽后) = 2/3 × L_坡; L_岔脊(兽前) = 1/3 × L_坡`;走兽置于岔脊段,数目按 06-03。参数:垂脊上段比例 2/3;岔脊(兽前)比例 1/3;岔脊走兽 5 或 7 件(工程做法示例);垂兽 1 只 + 兽角 1 对。
- **原文引文与出处**:《工程做法》卷四十三"凡調垂脊"条:"凡調垂脊,以每坡之長分爲叄分,上貳分卽垂脊……垂獸壹隻,獸角壹對,下壹分卽岔脊,用瓦條壹層,混磚壹層,上安獅馬或伍件,或柒件,圭角壹件"(识典古籍 https://www.shidianguji.com/zh/book/JZ001/chapter/1l6pcdtna9d0j);另见知乎《建筑考古》 https://zhuanlan.zhihu.com/p/9118050055
- **核验状态**:**通过**。甲:全条与卷四十三"凡調垂脊"原文逐字一致——三分、上二分垂脊、下一分岔脊、狮马或五件或七件、垂兽一只兽角一对;**2/3 与 1/3 是原文直给,非推演**。乙:同样逐句对上("兽座用方砖凿做,垂兽壹只,兽角壹对……上安狮马或伍件,或柒件")。乙附注(unverifiable):歇山戗脊与垂脊 45° 相交、套兽套角梁头属通识描述,无原文出处也无反证。

### 06-06 清式板瓦/筒瓦号数尺寸与瓦垄数(工程做法)

- **现代表述**:《工程做法》按瓦料号数定瓦垄:头号板瓦口宽 8 寸、每丈 11.1 垄;二号口宽 7 寸、每丈 12.5 垄;三号口宽 6 寸、每丈 14.2 垄;十样口宽 3.8 寸、每丈 22 垄。板瓦长:头号 9 寸、二号 8 寸、三号 7 寸、十样 4.3 寸。筒瓦长:头号 1 尺 1 寸、二号 9.5 寸、三号 7.5 寸、十样 4.5 寸。板瓦中高:头号 2 寸、二号 1.7 寸、三号 1.5 寸、十样 1 寸;灰当勾宽:头号 4 寸、二号 3.4 寸、三号 3 寸、十样 2 寸(用筒瓦加中高之一分半)。维基:清代普通筒瓦宽 4.5–2.5 寸,琉璃筒瓦宽 6.5–3 寸;普通板瓦宽 8–3.8 寸,琉璃板瓦 1 尺 1 寸–6 寸。
- **公式与参数**:`n_垄 = 面阔(丈) × k(号); k = {头号:11.1, 二号:12.5, 三号:14.2, 十样:22}`;`每垄瓦数 = (进深+出檐加举后坡长) / 露明长(见 06-07) − 1`(滴水/花边);`筒瓦每垄 = 坡长/L_筒 − 1`(勾头)。号数表:头号 口宽8寸/长9寸/中高2寸/每丈11.1垄;二号 7/8/1.7/12.5;三号 6/7/1.5/14.2;十样 3.8/4.3/1/22。筒瓦长 1.1 尺 / 0.95 尺 / 0.75 尺 / 0.45 尺。灰当勾宽 4 / 3.4 / 3 / 2 寸。琉璃瓦样数(清式营造则例)一样至九样,常用五/六/七样。工程做法用营造尺(1 尺≈32cm)。
- **原文引文与出处**:《工程做法》卷四十三"瓦以面阔得垄数"条、卷四十六"凡宽瓦"条:"如面濶壹丈貳尺,頭號板瓦口寛捌寸,每丈拾壹隴壹分;貳號口寛柒寸,每丈拾貳隴伍分;叄號口寛陸寸,毎丈拾肆隴貳分;拾樣口寛參寸捌分。每丈貳拾貳隴……每頭號筒瓦壹個,長壹尺壹寸,貳號長玖寸伍分;叄號長柒寸伍分;拾樣長肆寸伍分"(卷四十三 https://www.shidianguji.com/zh/book/JZ001/chapter/1l6pcdtna9d0j ;卷四十六 https://www.shidianguji.com/zh/book/JZ001/chapter/1l6pcdvk8daua);维基《筒瓦》 https://zh.wikipedia.org/wiki/筒瓦 、《板瓦》 https://zh.wikipedia.org/wiki/板瓦 ;知乎《古建屋面瓦件知多少》 https://zhuanlan.zhihu.com/p/1931419926163358365
- **核验状态**:**通过**。甲:板瓦口宽与每丈垄数、板瓦长、筒瓦长、板瓦中高、灰当勾宽共十六个数字逐一对上原文,无一讹。甲附注(imprecise):公式里`每垄瓦数 = 坡长/露明长 − 1`与`筒瓦每垄 = 坡长/L筒 − 1`是**规则自撰的推导式,原文未如此表述**;维基筒瓦/板瓦宽度区间与"灰当勾宽用筒瓦加中高之一分半"未亲验。乙:内部自洽性反算通过——100 寸 ÷11.1=9.00 寸、÷12.5=8.00 寸、÷14.2=7.04 寸、÷22=4.55 寸,即垄宽恒比口宽大约 1 寸(灰当),四个号数一致。实物旁证只到量级:故宫 2006 年太和殿大修揭瓦实测上檐东坡 89 垄、西坡 90 垄(二样黄琉璃),太和殿通进深 37m,上檐山面坡宽取 25–29m 反推单垄 280–325mm,落在头号板瓦垄宽 288mm(9 寸)量级——对得上,但上檐坡宽是估的,不构成 10% 级硬核验。
  - 乙的补注(采纳):表中"号"是**布瓦号数**,太和殿一类用的是琉璃"样"(琉璃板瓦宽 1 尺 1 寸–6 寸),**两套系统不可混算**;需要精确核垄时用故宫揭瓦实测 89/90 垄这类数据反标定。(故宫博物院《太和殿大修开始揭瓦检查》 https://www.dpm.org.cn/classify_detail/160353.html ;太和殿进深 37m https://news.gmw.cn/2021-08/07/content_35061112.htm)

### 06-08 清水脊构成(北方小式正脊)

- **现代表述**:清水脊为小式黑活硬山/悬山正脊中最高级、最复杂者,四合院正房与门楼用得最多;长随面阔外加两山墙外出之厚,板瓦取平、苫背、瓦条二层、混砖一层、扣脊筒瓦一层,每头鼻子一件、盘子一件、攛头二件、勾头二件;两端翘起的"鼻子"俗称蝎子尾(朝天笏),下承雕花草砖(平草/落落草/跨草)。不用于宫殿、王府等大式,适于合瓦或筒瓦小式屋面。
- **公式与参数**:`L_清水脊 = 面阔 + 2 × t_山墙外出`;`每端构件 = {鼻子1, 盘子1, 攛头2, 勾头2}`;`脊叠层 = 板瓦 + 苫背 + 瓦条×2 + 混砖×1 + 扣脊筒瓦×1`。
- **原文引文与出处**:《工程做法》卷四十六"凡調淸水脊"条:"凡調淸水脊長隨面濶,外加山墻外出之厚,用板瓦取平,苫背瓦條貳層,混磚壹層,扣脊筒瓦壹層,每頭鼻子壹件,盤子壹件,攛頭貳件,勾頭貳件"( https://www.shidianguji.com/zh/book/JZ001/chapter/1l6pcdvk8daua );卷四十三同条作"外加兩山墻外出之厚"( https://www.shidianguji.com/zh/book/JZ001/chapter/1l6pcdtna9d0j );维基《清水脊》"清水脊是中國傳統建築的一种屋脊形式,其两侧无吻兽,而是斜向上翘起","清水脊等级较低,一般不用于宫殿、王府等建筑"( https://zh.wikipedia.org/wiki/清水脊 );东方晨光《四合院房屋正脊的形式:清水脊》"'清水脊'是四合院住宅用得最多的一种正脊,也是等级较高的一种屋脊",并列"平草蝎子尾、落落草蝎子尾、跨草蝎子尾"( https://m.dfcgzs.com.cn/culture/shywh/11600.html )
- **核验状态**:**通过**。甲:原文逐字对上(长随面阔外加山墙外出之厚、瓦条二层、混砖一层、扣脊筒瓦一层、每头鼻子一件盘子一件攛头二件勾头二件);维基定义句与蝎子尾/朝天笏对上;"四合院用得最多、等级较高"确出自东方晨光文,平草/落落草/跨草亦在该文。甲附注(imprecise):卷四十三同条多一"兩"字("外加兩山墻外出之厚"),规则称两卷"同文"略粗。乙:同样逐字命中,长度算法与四种端部构件件数全对;蝎子尾(朝天笏)、四合院正房与门楼常用属二手描述但无反证。
  - 两人共同附注(unverifiable):**清水脊的具体高度尺寸未在任何可访问来源中找到**(马炳坚《北京四合院建筑》未上网,东方晨光文亦无数值)。

### 06-02 大式瓦作与小式瓦作的区分

- **现代表述**:大式瓦作:筒瓦(或琉璃瓦)骑缝盖瓦、板瓦为底瓦,屋脊调大脊、安吻兽/垂兽/戗兽/仙人走兽,檐口用勾头滴水;用于宫殿、庙宇、王府等有斗拱或等级较高建筑。小式瓦作:合瓦(阴阳瓦,北方)/蝴蝶瓦(小青瓦,南方)以板瓦为底瓦和盖瓦,正脊做清水脊、皮条脊、鞍子脊、过垄脊等,无吻兽,檐口用花边瓦与滴水;用于民居和次要建筑。硬山民居"屋面多用青瓦,且仅能使用板瓦,不能使用筒瓦或琉璃瓦"。《工程做法》即以卷四十三"歇山硬山各项瓦作做法(大式)"与卷四十六"硬山悬山小式各项瓦作做法"分列。
- **公式与参数**:`if grade in {宫殿,坛庙,王府正殿,寺庙主殿} → tile_system='大式'(盖瓦=筒瓦|琉璃筒瓦; 正脊=大脊+正吻; 垂脊=垂兽+走兽; 檐口=勾头+滴水) else tile_system='小式'(盖瓦=板瓦(合瓦/蝴蝶瓦); 正脊∈{清水脊,皮条脊,鞍子脊,过垄脊}; 檐口=花边瓦+滴水; 禁筒瓦/琉璃)`。
- **原文引文与出处**:《工程做法》目录卷四十三作"瓦作大式"、卷四十六作"瓦作小式"( https://www.shidianguji.com/zh/book/JZ001/chapter/1l6pcbymea5gj );卷四十三卷名"歇山硬山各項瓦作做法開後"( https://www.shidianguji.com/zh/book/JZ001/chapter/1l6pcdtna9d0j );卷四十六"工程做法卷四十六·硬山懸山小式各項瓦作做法開後"( https://www.shidianguji.com/zh/book/JZ001/chapter/1l6pcdvk8daua );"大式瓦作以筒瓦骑缝,屋脊上装有脊瓦、吻兽等构件"(知乎《古建屋面瓦件知多少》 https://zhuanlan.zhihu.com/p/1931419926163358365 ,搜狐镜像 https://www.sohu.com/a/407466438_617491 );维基《硬山顶》"由于硬山式屋顶的等级较低,屋面多用青瓦,且仅能使用板瓦,不能使用筒瓦或琉璃瓦。"( https://zh.wikipedia.org/wiki/硬山顶 )

- **更正值(可编码,合两人)**:
  ```
  提栈_起算 = 界深(尺) / 10            # 界深3.5尺→3.5算, 4尺→4算
  提栈_i    = 提栈_起算 + i × 0.5      # 逐界递增约半算, 至脊部可达对算 1.0
  飞椽 allowed iff 提栈 > 0.4          # 严格大于:四算这一档本身禁飞椽
  发戗 allowed iff 提栈 > 0.5          # 严格大于:五算这一档本身禁发戗
  戗角坡度 = 提栈 / 1.414              # 折减后约 3.5 算(0.5/1.414≈0.354)
  ```
  苫背≤50mm、脊童柱硬提三寸、坡度>五算加瓦钉三项标孤证 low。
