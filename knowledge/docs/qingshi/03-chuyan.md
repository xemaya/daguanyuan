# 03 出檐、飞椽与翼角

日期:2026-09-10 | 章 id:`03-chuyan` | 规则 21 条:通过 12 / 存疑 6 / 驳倒 3

## 本章在推导链里的位置

本章是屋面轮廓的最后一环,也是全书里南北分歧最大的一章。上游给定的是**檐柱高**(小式)或**斗口**(大式)与**桁条径**;本章由这两个输入先推出**上檐出**(03-01 / 03-02),再把上檐出三等分为檐椽出与飞椽出(03-03),由桁径推出**椽径**(03-06)——椽径一旦定下,整个翼角的所有量都以它为模数:冲三(03-09)、翘四(03-10)、撇半椽(03-11)、角梁断面(03-12)、翼角椽根数(03-15)、连檐瓦口(03-18)。所以**椽径是本章的"分"**,它的误差会等比例放大到屋角每一个点上。

下游输出两组东西:一组是可以直接建模的构件(檐椽、飞椽、老角梁、仔角梁、翘飞椽、大小连檐、里口木、瓦口),另一组是屋面轮廓的控制点(檐口线、起翘曲线、翼角下皮线),后者要交给瓦作章去铺瓦。

**本章对大观园项目的特殊风险**:清官式的整套出檐规则以"檐柱高"和"椽径"为基准,而江南(《营造法原》/香山帮)的出檐由**界深**决定、与柱高脱钩,起翘由**嫩戗泼水角**决定、与椽径无关。核验中乙方反复指出:3/10 柱高这条口诀直接套到江南题材上会把檐挑长两三成(03-01),翼角的"椽槽"做法在江南根本不存在(江南用戗山木垫高,03-16),"冲三"在江南是"放叉一尺"的定值而非椽径倍数(03-09)。**实现时必须把北方档与江南档分成两套函数,不要合并求平均。**

核验方式:每条规则两名核验者。甲主核**原文文本**(識典古籍《工程做法》卷一逐字比对 + 建筑史学刊论文版本核对);乙主核**算术自洽与实测/异源交叉**(《营造法原》江南体系反向验证、清代档案实录)。二人均未驳倒记"通过";一人驳倒记"存疑",两人原话与更正值全部抄录以便自判;二人均驳倒记"驳倒",列入章末"已否决"。

## 通过

### 03-01 无斗拱上檐出=檐柱高 3/10

- **现代表述**:无斗拱建筑(小式,或无斗拱大式),由檐柱中至飞椽头外皮(无飞椽则至檐椽头外皮)的水平距离即"上檐出",定为檐柱高的十分之三。工匠口诀:"柱高一丈,平出檐三尺,再加拽架"。
- **公式与参数(可直接编码)**:
  ```
  上檐出 = 0.3 × 檐柱高        # 檐柱中线 → 飞椽头外皮,水平投影
  起算点 = 檐柱中线
  止点   = 飞椽头外皮(无飞椽则檐椽头外皮)
  允许上限 = 1/3 × 檐柱高      # 故宫词条记"或采用按柱高的1/3出檐的惯用做法"
  ```
- **原文引文与出处**:马炳坚《中国古建筑木作营造技术》(古建网转录):"4、上出:无斗拱大式或小式建筑上檐出尺寸定为檐柱高的3/10。其中2份为檐椽出头,一份为飞椽出头。""6、上檐出:檐头挑出由飞椽前端至檐柱中的水平距离称上檐出。"(https://www.gujian.vip/sys-nd/199.html);故宫博物院词条:"明代以后的建筑术语中有'檐步五举,飞椽三五举;柱高一丈,平出檐三尺,再加拽架'的说法,或采用按柱高的1/3出檐的惯用做法。"(https://www.dpm.org.cn/lemmas/243829.html);另见百度百科"出檐"(https://baike.baidu.com/item/%E5%87%BA%E6%AA%90/4945928)、ICOMOS《文物保护工程专业人员学习资料·古建筑》p.181(http://www.icomoschina.org.cn/Upload/File/202108/20210804181048_6645.pdf)。
- **核验状态**:**通过**(乙附 imprecise 备注)。
  - 甲(文本):不驳倒。起算点(檐柱中)/止点(飞椽前端)/0.3 系数三项与马炳坚原文完全一致;故宫口诀逐字存在,"或采用按柱高的1/3"亦确记。两处小瑕:①口诀末"再加拽架"只对带斗拱建筑成立,放进"无斗拱"规则的表述里读来略拧,但这是故宫原文自身的连写,非规则伪造;②规则把 quote 标为梁思成《清式营造则例》,而实际逐字来源是马炳坚转录,属转述层级标注问题,未影响数值。
  - 乙(实测/异源):不驳倒,但标 **imprecise**。0.3 本身没被驳倒,然而**找不到任何一条北方清代小式民居的独立实测**来验它——故宫博物院院刊(钦安殿大木尺度、长春宫大木结构、中轴线实测图集札记)、四合院测绘检索,全部只给平面/斗口/举架,不给上檐出。唯一能算的是档案实录:《万寿山准底册》(光绪十三年勘察)记颐和园花承阁"下层檐柱高一丈一尺,上檐柱高一丈,台明高二尺,下出二尺三寸";用 0.3 柱高配 0.8 下出反推,配上檐柱高 10 尺时下出应 2.40 尺(实录 2.30,−4.3%,过关),配下层柱高 11 尺时应 2.64 尺(实录 2.30,+14.8%,不过关),取哪根柱高含糊,故只能算"半个旁证"(http://sanyamuseum.com/a/3/2022/0815/1140.html)。
  - **乙的更正(江南分档,建议采纳)**:本条限定为**北方清官式无斗拱做法**。江南另立一条:`上檐出 = 1.5 × 出檐椽平出`,出檐椽斜长 1 尺 6 寸 ~ 2 尺 4 寸且 ≈ 界深之半,**不按柱高取值**。配《营造法原》自己的厅堂例(正间 1 丈 6 尺 → 次间/檐高 1 丈 2 尺 8 寸),上檐出水平投影 2.19~3.28 尺,比值 **0.17~0.26**,对 0.3 的误差 −43%~−14.5%;只有檐高压到 1 丈且出檐取上限 2.4 尺时才勉强 +9.4%。即**江南出檐由界深决定、与柱高脱钩,3/10 口诀套到大观园这种江南题材上会把檐挑长约两三成。**

### 03-03 檐椽出:飞椽出 = 2:1

- **现代表述**:上檐出分三份,檐椽出占三分之二,飞椽出占三分之一。带斗拱时 21 斗口中,檐椽出 14 斗口、飞椽出 7 斗口。
- **公式与参数(可直接编码)**:
  ```
  檐椽平出 = 2/3 × 上檐出
  飞椽平出 = 1/3 × 上檐出
  有斗拱:  檐椽平出 = 14 × 斗口 ; 飞椽平出 = 7 × 斗口   # 合 21 斗口
  ```
- **原文引文与出处**:古建网转录马炳坚:"无斗拱小式大木的上檐出按柱高的十分之三定。其檐椽出挑为上檐出的三分之二、飞椽为三分之一。"(https://www.gujian.vip/sys-nd/199.html);清《工程做法》卷一飞檐椽条:"凡飛檐椽以出檐定長……叄分分之,出頭壹分"(https://www.shidianguji.com/zh/book/7483498839458971659/chapter/1kvwjcv6sodva);程枭翀《关于〈工程做法〉若干问题的思考》引《营造算例》:"(飞檐椽)长按挑檐桁中往外平出若干,用三分之一,即得飞头平出;按三五举加斜除后斜勾分位,净若干……再按一头三尾即通长。"(https://www.jgcm.ac.cn/jah/cn/article/pdf/preview/10.12329/20969368.2026.02015.pdf);《营造法原》:"常于出檐椽之上,加钉飞椽……其长约为出檐椽之半"。
- **核验状态**:**通过**(两人均判 ok,唯口诀名"椽三飞一"来源存疑)。
  - 甲(文本):不驳倒。2/3 : 1/3 逐字对上马炳坚。带斗拱的 14/7 拆分规则本身没给出处,但《营造算例》原文"(飞檐椽)长按挑檐桁中往外平出若干,用三分之一,即得飞头平出"——1/3 正是施加在"挑檐桁中往外平出"(即 21 斗口)上,故飞椽出 7 斗口、檐椽出 14 斗口成立,这一步没有过度推演。**唯一未证实的是"椽三飞一"这四字口诀本身**:多轮检索未见任何原典或匠书出现,建议编码时不要把这四个字当术语写进注释。
  - 乙(交叉):不驳倒,判"**本章最硬的一条**"。两个互不相干的传统各自独立给出 2:1 ——北方《工程做法》"出檐七尺五寸,按一一五加举,得长八尺六寸二分,出头一分,得长二尺八寸七分",即飞头取加举后出檐的 1/3、檐椽占 2/3;江南《营造法原》"其长约为出檐椽之半",即檐椽出:飞椽出 = 2:1。**同一个比值,误差 0%。**

### 03-04 飞椽头尾比与通长(《工程做法》原文)

- **现代表述**:《工程做法》:飞檐椽以出檐定长,出檐按 1.15 加举后三等分,出头一份为飞头、后尾两份半;通长 = 3.5 倍飞头 = 7/6 倍出檐加举长;断面见方同檐椽径。马炳坚/《营造算例》系统则按"一头三尾"。
- **公式与参数(可直接编码)**:
  ```
  # 档 A:《工程做法》
  飞头   = (出檐 × 1.15) / 3
  飞尾   = 2.5 × 飞头
  飞椽通长 = 3.5 × 飞头 = (7/6) × 出檐 × 1.15
  飞椽见方 = 檐椽径
  # 档 B:《营造算例》/ 马炳坚
  飞尾   = 3 × 飞头
  飞椽见方 = 椽径 或 0.95 × 椽径
  # 单元测试(工程做法例):出檐 7.5 尺 → 8.62 尺 → 头 2.87 / 尾 7.17 / 通长 10.04 尺
  ```
- **原文引文与出处**:清工部《工程做法》卷一·九檩单檐庑殿·飞檐椽条:"凡飛檐椽以出檐定長,如出檐柒尺伍寸,按壹壹伍加舉,得長捌尺陸寸貳分,叄分分之。出頭壹分,得長貳尺捌寸柒分,後尾貳分半,得長柒尺壹寸柒分,加之,得飛檐椽通長壹丈肆分,見方與檐椽徑寸同。"(https://www.shidianguji.com/zh/book/7483498839458971659/chapter/1kvwjcv6sodva);程枭翀 2026:"以1/3定飞檐椽头,再以2.5倍飞檐椽头定后尾,得飞檐椽通长尺寸,折3.5倍飞檐椽头尺寸或7/6出檐加举尺寸。"(注:参见允礼等《工程做法》卷一,雍正十二年〔1734〕刊本,日本内阁图书文库藏)(https://www.jgcm.ac.cn/jah/cn/article/pdf/preview/10.12329/20969368.2026.02015.pdf);古建网转录马炳坚:"飞椽(即飞头):长按檐平出的1/3为飞头头部,按三五举一零六加斜,再加三尾(尾按头部尺寸,一头为一尾)即长,方按椽径或椽径的十分之九五。"(https://www.gujian.vip/sys-nd/199.html)
- **核验状态**:**通过**(两人均判 ok,且有专业论文的版本核对背书)。
  - 甲(文本):不驳倒。逐字逐数全部核实,算术自洽(7.5×1.15=8.625≈8 尺 6 寸 2 分;÷3=2.875≈2 尺 8 寸 7 分;×2.5=7 尺 1 寸 7 分;合计 10.04 尺)。程枭翀依雍正十二年刊本复核,明确写出"折3.5倍飞檐椽头尺寸或7/6出檐加举尺寸",与规则公式一字不差。"一头三尾"档亦双源坐实。**规则把两档并列而不擅自合并,处理正确。**
  - 乙(交叉):不驳倒。原文与算术双重闭合;3.5×2.87=10.045 尺 vs 原文"飞檐椽通长壹丈肆分"=10.04 尺,**误差 0.05%**。

### 03-05 飞椽举架(三五举)与加斜

- **现代表述**:《清式营造则例》《营造算例》均记飞椽为"三五举"(飞头按 0.35 坡度,加斜系数 1.06);但《工程做法》原文檐椽与飞檐椽长度**均按 1.15(五举)加举**计算,安装后飞椽实际斜率约 0.46。两法并存,须由上层选定。
- **公式与参数(可直接编码)**:
  ```
  # 则例/算例档
  飞头斜长 = 飞头平出 × 1.06          # 三五举 0.35
  # 工程做法档
  飞椽长   = 出檐 × 1.15 再三等分      # 五举
  檐步举   = 0.5 (五举), 加斜 1.12
  # 安装后实测斜率(程枭翀):飞椽 ≈ 0.46 ; 檐椽 ≈ 0.53
  ```
- **原文引文与出处**:程枭翀《关于〈工程做法〉若干问题的思考》第 5 节"飞檐椽举架"引梁思成《清式营造则例》p.41:"最下一举多是五举,飞椽则三五举,最上一举往往在九举之上。";同文:"应当注意,此处檐椽和飞檐椽的加举系数均为1.15,即五举。""檐椽受挑檐桁和老檐桁径差的影响,安装后的斜率约为0.53;飞檐椽需要贴合顺望板,且椽头应落于出檐线上,安装后的斜率约为0.46。所以飞檐椽'三五举'的说法不能视作清式的制度,还需要更多的实例来印证。"(https://www.jgcm.ac.cn/jah/cn/article/pdf/preview/10.12329/20969368.2026.02015.pdf);古建网举架加斜法表:"三五举一〇六;……五举一一二;"(https://www.gujian.vip/sys-nd/199.html)
- **核验状态**:**通过**(两人均判 ok;confidence medium,因两套制度本身冲突)。
  - 甲(文本):不驳倒。四项待验全中,引文页码(p.41)正确,规则 notes 的转述准确无夸大。**规则把两法并存而不强行统一,是对原文的忠实处理。**
  - 乙(交叉):不驳倒。程枭翀原文核实,0.46 与"不能视作制度"的判断逐字对上。
  - **两人共同补充(建议采纳)**:同段还给出**檐椽安装后斜率约 0.53**(非 0.50),对规则的"檐步五举 0.5"为 +6%,仍在 10% 内;建模时可一并采用 0.53/0.46 这组安装后实测值。

### 03-07 椽当 = 一椽径,每间椽数成双档

- **现代表述**:椽子空档随椽径一份(椽当 = 椽径),故椽中距 = 2 椽径;每间椽数应成双档,随数均匀分布。
- **公式与参数(可直接编码)**:
  ```
  椽当   = 1 × 椽径
  椽中距 = 2 × 椽径
  每间椽档数 = 偶数   →  每间椽根数 = 档数 + 1 = 奇数(一椽坐中)
  ```
- **原文引文与出处**:清《工程做法》卷一檐椽条:"每椽空檔隨椽徑壹分,每間椽數俱應成雙檔之寬窄,隨數均勻。";同卷顺望板条(独立佐证椽中距):"凡順望板,以椽檔定寬,如椽徑叄寸伍分,檔寬叄寸伍分,共寬柒寸。"(https://www.shidianguji.com/zh/book/7483498839458971659/chapter/1kvwjcv6sodva);另见今日工匠《翼角椽的布置》(https://zhuanlan.zhihu.com/p/360010545)。
- **核验状态**:**通过**(甲附 imprecise 备注)。
  - 甲(文本):不驳倒。原句逐字无误;椽中距 = 2 椽径另有顺望板条独立佐证(3.5 寸 + 3.5 寸 = 7 寸)。**需标注**:规则括注"即椽根数为奇数、档数为偶数"是**几何推导而非原文字面**(原文只说"成雙檔"),该推论在"档数偶数→两端各有一椽→椽数=档数+1 为奇数、且一椽坐中"的计数约定下成立,但换一种边界计数约定(相邻间共用边椽)结论会变。**作为建模约束可用,但不应写成原典原话。**
  - 乙(交叉):不驳倒。"椽当=1椽径、椽中距=2椽径、每间档数为偶(故椽根数为奇、坐中)全部成立,无可驳处。"

### 03-08 檐椽长

- **现代表述**:无斗拱檐椽长 = (檐步架 + 2/3 上檐出) 按五举加斜 1.12(马炳坚另加半椽径);带斗拱另加斗拱出跳。《工程做法》原文:出廊并出檐共长按 1.15 加举得通长,内除飞檐头长得檐椽净长。
- **公式与参数(可直接编码)**:
  ```
  # 无斗拱(马炳坚)
  L_檐椽 = (檐步架 + 2/3 × 上檐出) × 1.12 + 0.5 × 椽径
  # 工程做法
  L_檐椽净 = (出廊 + 出檐) × 1.15 − 飞头长
  # 单元测试:出廊 5.5 尺 + 出檐 7.5 尺 = 13 尺 → 14.95 尺 − 2.87 尺 = 12.08 尺
  ```

### 03-15 翼角椽根数

- **现代表述**:矩形建筑翼角椽根数 = (檐/廊步架 + 斗拱出踩 + 檐平出) ÷ (一椽加一档 = 2 椽径),取整;结果为单数即用之,双数则减 1。《工程做法》:"翼角翹椽以成單爲率,如逢雙數,應改成單"。多边形:六角 ÷3 椽径、八角 ÷4 椽径、五角 ÷2.5 椽径。
- **公式与参数(可直接编码)**:
  ```
  # 现代匠作口径
  N = floor((檐步架 + 出踩 + 檐平出) / (k × 椽径))
  # 《工程做法》原典口径(两名核验者一致要求并列)

  k = 2(矩形) | 2.5(五角) | 3(六角) | 4(八角)

  翼角翘椽长径 = 平身檐椽同
  ```

  ```
  里口木高 = 椽径 + 1.5 × 望板厚 ≈ 1.45~1.5 椽径   # 原文例 5.1寸/椽径3.5寸 = 1.457;删去"约1.3椽径"
  大连檐   : 高 = 厚 = 1 × 椽径 ;  可将"高"加 1/10 至 1.1 椽径(非宽,无 1.2 一档)
  小连檐   : 宽 = 1 × 椽径 ;
             厚 = 1.2 × 望板厚(马炳坚) | 1.5 × 望板厚(《工程做法》翼角段)   # 须分档标注
  瓦口     : 高 = 0.5 × 椽径 ;
             厚 = 0.5 × 高(《工程做法》"以本身之高折半定厚") | 0.3 × 高(马炳坚)  # 两档,删去"1/2~3/10"这种含混区间写法
  顺望板厚 = 椽径 / 3
  ```

### 03-20 江南水戗发戗 vs 嫩戗发戗(几何规则)——**驳倒**

- **原规则(错)**:苏州(营造法原)戗角两法:水戗发戗只有老戗、木构不起翘,起翘全由瓦作戗脊叠涩完成,**与清官式(老角梁+仔角梁)基本同**;嫩戗发戗在老戗端斜插嫩戗,老戗与嫩戗分别与水平线所成两锐角大致相等,故屋坡决定起翘高度;**θ_嫩戗 ≈ θ_老戗,∠(老戗,嫩戗) = 180° − 2θ_老戗**,经验值 122°~130°;嫩戗根从老戗头缩入 3 寸;菱角木+扁担木拼高 ≥ 嫩戗水平高的 2/3,宽为嫩戗头宽的 0.7~0.8;**实例起翘(网师园濯缨水阁)约 45°**。
- **原文引文与出处**:刘敦桢《苏州古典园林》(三)建筑构造·1 屋顶·(3)屋角:"水戗发戗的构造较简易,只有老戗(即老角梁)没有嫩戗(子角梁),而木构件本身不起翘,仅戗脊端部翘起。嫩戗发戗的构造较复杂,其老戗下端斜立嫩戗,故屋檐两端升起较大。""老戗和嫩戗相交的角度,一般须是老戗、嫩戗和水平线成的两锐角大致相等,而老戗与水平线所成角度是根据屋顶坡度而形成的。因此,屋顶坡度决定后,也就决定了屋角起翘的高低。""两种发戗(屋角起翘)的木构造虽不同,但水戗(戗脊)的构造大体相同。"(https://ylj.suzhou.gov.cn/szsylj/ylwh/201903/e2e2a80479bf46b7977a8c6ece126555.shtml);《营造法原》发戗详细尺寸制度:"嫩戗连于老戗,称坐势,其戗面离老戗头缩进三寸。二戗相交之角度,规定泼水自一寸到一寸二分……合39°48′。殿庭用料较巨,泼水以泼足为宜。亭阁较小,泼水宜于酌收,至少为一寸到一寸六分,合32°。";另见 https://www.nbgjz.com/1298.html、https://www.sohu.com/a/443936847_617491、https://www.sohu.com/a/367273490_755852、https://baike.baidu.com/item/%E5%AB%A9%E6%88%97%E5%8F%91%E6%88%97/3501768。
- **核验状态**:**驳倒**(甲 wrong + 乙 wrong)。
  - **甲(文本)驳倒**,原话:"核心引文属实……但 statement 里'水戗发戗……与清官式(老角梁+仔角梁)基本同'是**对原文的误读**:刘敦桢明写水戗发戗'只有老戗(即老角梁)没有嫩戗(子角梁),而木构件本身不起翘'——**恰恰与有仔角梁起翘的清官式相反**;原文中'大体相同'四字说的是**两种江南发戗之间的水戗(戗脊)构造相同**,被错接到了清官式头上。另外 122°~130°、嫩戗根缩入 3 寸、菱角木/扁担木高宽比、檐瓦槽深外 5 分内 1.5 寸、网师园濯缨水阁约 45°,**在所标 source(刘敦桢《苏州古典园林》屋角节)全文中一概不存在**(全文检索无'菱角木''扁担木''122''130''三寸'等字样),规则却把该书列为 source.book。"
  - **乙(交叉)驳倒**,原话:"经验角 122°~130° 是对的,而且我把这个角的原始出处挖出来了。《营造法原》……即**夹角 = 90° + 泼水角**:atan(1/1.2) = 39.81° → 129.8°(殿庭),atan(1/1.6) = 32.01° → 122.0°(亭阁),正好张出 122~130 这个区间,且**由建筑等级/体量决定,与屋面坡度无关**。卡片的'∠=180°−2θ_老戗'推不出这个区间:法原自己的算例给老戗坡度 = 提栈/1.414,五算时 = 0.3536 → θ = 19.5° → 公式得 141.1°,对 129.8° 偏 +8.7%、对 122° 偏 +15.6%,后者超 10%;而且反推出的 θ_嫩戗 = 69.8°,**与'两锐角大致相等'直接打架**。刘敦桢那句'两锐角大致相等'是描述性判断,不能当生成式用。附:卡片列的'网师园濯缨水阁起翘约 45°'我查不到出处,且与上述几何不相容(嫩戗与水平 45° 时夹角约 155°),建议删。缩入三寸、檐瓦槽'外深五分,内深一寸半'、菱角木扁担木拼高 ≥ 嫩戗水平高 2/3、宽为嫩戗头宽七~八折,均已核实。"
- **更正值(采用)**:
  ```
  # 定性(刘敦桢原文)
  水戗发戗:只有老戗、无嫩戗,木构本身不起翘,仅戗脊端部翘起
           —— 此点与清官式(老角梁+仔角梁,由仔角梁起翘)**相反**,不是"基本同";
              "大体相同"原指两种江南发戗之间的水戗(戗脊)构造。
  # 几何(《营造法原》原文,取代原生成式)
  ∠(老戗, 嫩戗) = 90° + 泼水角
  泼水角 = atan(1/k) ,  k = 1.2(殿庭"泼足", 39°48′ → 夹角 129.8°)
                       ~ 1.6(亭阁"酌收", 32°    → 夹角 122.0°)
  # 删除:∠ = 180° − 2θ_老戗 ;  θ_嫩戗 ≈ θ_老戗 ;  濯缨水阁 45°
  # 已核实可保留
  嫩戗根缩入老戗头 = 3 寸
  檐瓦槽深 = 外 5 分 / 内 1 寸 5 分
  菱角木+扁担木拼高 ≥ 2/3 × 嫩戗水平高 ;  宽 = 0.7~0.8 × 嫩戗头宽
  # 乙补充的法原原文数(建议一并采纳)
  嫩戗全长 = 飞椽长 × 3
  猢狲面泼水 = 1 寸 ~ 1 寸 4 分半,合 55°24′
  老戗长 = (出檐椽水平长 + 放出一尺) × 1.4,再依提栈求弦
  老戗断面依坐斗(四六式:高 4 寸 阔 6 寸);戗梢按戗头八折(高 3 寸 2 分 阔 4 寸 8 分)
  ```
