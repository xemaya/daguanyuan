## 0 本篇怎么用

`ART_DIRECTION.md` §1.5 立了两件事:优先级栈(**原文 > 清式 > 法式 > 江南**)与三个 tier。本篇把这两件事落成可编码的东西:

- **§1** 给每个 tier 指定**唯一**参数集与规则 id 白名单,以及所有默认参数。构件 agent 拿到一个 region 的 `style` 权重后,只准从本篇 §1 对应 tier 的那一列取数,不许跨 tier 混取、不许手拍。
- **§2** 给 14 个景点各一条记录,把原文**已经定死**的属性与**必须由参数集补**的属性分开。定死的那些是硬约束:装配器不得覆盖,反审时改动即退回。补的那些由 §1 推。
- **§3** 把原文与清式/法原打架的 12 处一次裁完,全部按优先级栈判原文胜,并记下代价。

三条元规则:

1. **规则 id 白名单制**。§1 每个 tier 列了准用 id 与禁用 id。禁用的多半是被两名核验者驳倒的条(如 01-05 攒数推面阔、02-02 步架定尺、04-11 小式 D 模数、06-01 屋顶等级序列),照抄会把几何算歪 26%~82%,一律不得引用。
2. **生成方向是反的**。清式"斗口一路乘到底"只有上半截(斗口→构件断面)在实物上成立,下半截(斗口→柱高/面阔)全被驳(04 章结论)。所以 Tier A 也先由开间与柱高定规模,**再反算斗口**,再用斗口派生断面。
3. **尺值只有一个**。全项目采营造尺库平制 **1 尺 = 0.32 m**(`docs/plan/03-scale.md` §1.2 已裁)。《营造法原》条文原本按苏作尺 0.275 m,凡引 05 章数值须显式标注换算档,禁止两套尺混用。

### 4. 潇湘馆 — Tier B

### 5. 稻香村 — Tier C-r

- **原文**:第十七回「轉過山怀中,隱隱露出一帶黃泥筑就矮牆,牆頭皆用稻莖掩護。有幾百株杏花,如噴火蒸霞一般。里面數楹茅屋。外面卻是桑,榆,槿,柘,各色樹稚新條,隨其曲折,編就兩溜青篱。篱外山坡之下,有一土井,旁有桔槔轆轤之屬。下面分畦列畝,佳蔬菜花,漫然無際。」(`07-11`) ‖ 「忽見路旁有一石碣,亦為留題之備……只是還少一個酒幌。明日竟作一個,不必華麗,就依外面村庄的式樣作來,用竹竿挑在樹梢。」(`07-12`) ‖ 「引人步入茆堂,里面紙窗木榻,富貴气象一洗皆盡。」(`07-13`) ‖ 「遠無鄰村,近不負郭,背山山無脈,臨水水無源,高無隱寺之塔,下無通市之橋,峭然孤出,似非大觀。」(`07-14`) ‖ 第十八回 赐名「杏帘在望」→「浣葛山莊」(`07-37`)

## 3 冲突裁决

裁决格式:**争点 → 原文方 → 形制方 → 裁决 → 代价**。全部按 `ART_DIRECTION.md` §1.5 优先级栈(原文 > 清式 > 法式 > 江南)判,**12 条无一例外由原文胜**,但每一条都必须记下被牺牲的那一侧,不许假装它不存在。

### R-01 园门五间 vs 府门三间(礼制越格)

- **原文方**:第十七回园门「正門五間」;第三回府门「三間獸頭大門」(`07-53`,存疑)。**园门比府门还高一等。**
- **形制方**:清代门第规制中,门的开间数是身份标尺,附属园林的园门不应高于本府正门。颐和园排云殿面阔七间、仁寿殿九间——五间是相当高的规格。
- **裁决**:**原文胜,园门做 5 间。** 定性为"省亲别墅特例的礼制越格",是小说自身的文学安排。
- **代价**:此值**不可反向外推**为清代规制。任何下游模块不得用"园门五间"去推贾府等级、去定其他建筑的间数上限,也不得为了"合规"而把府门改成五间或把园门改成三间。`07-01` 乙的提醒原样保留。

### R-02 「桶瓦泥鳅脊」的形制归属

- **原文方**:第十七回「上面桶瓦泥鰍脊……并無朱粉涂飾」。
- **形制方**:三处打架。①**筒瓦**属大式瓦作,`06-02` 明说小式"禁筒瓦/琉璃",硬山民居"仅能使用板瓦";②**泥鳅脊**不在《营造法原》江南脊型序列(龙吻/哺龙/哺鸡/纹头/雌毛/甘蔗/游脊)中,`07-01` 乙**未能独立核到**它的位置,标 unverifiable;③**并无朱粉涂饰**又直接否掉官式大式配套的彩画。三者拼在一起,不属于清式大式,也不属于苏式小式。
- **裁决**:**原文胜,三条照做,不求形制自洽。** 具体落地:瓦作走 A 档大式筒瓦(灰陶,不上琉璃);正脊按"泥鳅"字面建模为**低平圆脊**(截面近半圆、无脊兽、无翘头),几何上归入甘蔗脊/黄瓜环脊族但**在代码里单独命名 `nqiu_ridge`,不并入任一既有脊型**;油饰按江南档,梁枋只上桐油不上彩画。
- **代价**:正门成为全园唯一一个"大式瓦 + 无彩画 + 自造脊型"的混合体,它的做法**不可复用**到任何其他建筑。`nqiu_ridge` 是本项目发明的构件,confidence = L4,注释里必须写明"泥鳅脊在江南脊型表中的位置未核到"。

### R-03 稻香村茅屋不入任何形制体系

- **原文方**:第十七回「黃泥筑就矮牆,牆頭皆用稻莖掩護……里面數楹茅屋」;`07-13`「紙窗木榻」。
- **形制方**:清《工程做法》与《营造法原》都是**瓦作体系**——`06-02` 连最低等的硬山民居也是板瓦;`01-03` 小式定义里没有"茅屋"这一档;`05-07` 提栈上限表最低是"租四"(出租房四算),也预设了瓦顶。**茅苫屋面在两套书里都不存在。**
- **裁决**:**原文胜。稻香村单列 C-r 乡野子档,完全不接模数推导链**(§1.4)。不算提栈、不铺瓦、不做脊件、不发戗。
- **代价**:①稻香村的几何**没有任何形制文献背书**,全部由原文 + 项目判断给,confidence = L4;②它是全园唯一一处不能用 `src/fashi` 校核的建筑,反审时只能对着 `07-11`/`07-13` 逐句核。
- **附带裁决**:`07-14` 宝玉那段"六无"批评是原文自带的**负面评价**,同样是原文。建模时**必须保留它所批评的状态**——远无邻村、背山无脉、临水无源、峭然孤出。**不许**为了让场景"更真实"而补上远山、村落、水源。稻香村在原著里就是假的,假是它的设计意图。

### R-04 蘅芜苑五间 + 四面出廊超出小式规格

- **原文方**:第十七回「上面五間清廈連著卷棚,四面出廊」。
- **形制方**:`01-03` 清式小式限定"3 间至 5 间、通进深不多于 7 檩",5 间已顶格;而**四面出廊(周围廊)** 在清式属大式特征("可用周围廊、庑殿、歇山、重檐")。蘅芜苑是宝钗的住处,按功能属 Tier B 住宅。
- **裁决**:**原文胜。Tier B 破格允许 5 间 + 四面出廊。** 但破格只放开**规模**,不放开**等级标志**:仍然**不加斗拱、不上筒瓦、不做彩画、不设正吻走兽**。
- **代价**:蘅芜苑成为 B 档里体量最大的一处,与潇湘馆的"小小两三间"形成极大反差——这个反差本身是原文给的(`07-08` vs `07-19`),保留。副作用是 B 档的间数上限在代码里必须写成 5 而不是 3,其他 B 档建筑不得因此自动放大。

### R-05 正殿「金辉兽面、彩焕螭头」vs 艺术圣经「苏式园林无朱红金黄官式彩画」

- **原文方**:第十七回「玉欄繞砌,金輝獸面,彩煥螭頭」,贾政评「太富麗了些」。
- **形制方**:`ART_DIRECTION.md` §1 硬规则:"苏式园林没有朱红金黄的官式彩画。颜色饱和度 45–65%",色板里"金 `#c9a84c`"标注为"匾额字,**唯一金属**"。
- **裁决**:**原文胜,但解禁范围严格限定。** Tier A 主轴(正殿、大观楼、缀锦阁、含芳阁)允许:**兽面构件、螭头构件上金彩**;栏杆用白石(玉栏)。**仍然禁止**:梁枋和玺/旋子彩画、朱红柱身、黄色琉璃。B/C/C-r 三档完全不解禁。
- **代价**:这是 §1.5 优先级栈第 1 级压 §1 硬规则的一次,**《艺术圣经》§1 色板"金 = 唯一金属"那条须同步补注"A 档兽面/螭头例外"**,否则棚拍反审会把正殿判退回。贾政那句"太富丽了些"是原文自带的态度——正殿要比全园其他地方富丽一档,但也仅止一档,不做成紫禁城。

### R-06 全园禁琉璃 vs 省亲行宫本可用绿琉璃

- **原文方**:第十七、十八回把正门、正殿、牌坊写了个遍,**没有一处写琉璃、写黄瓦、写绿瓦**。正门明写"桶瓦"(灰陶筒瓦)、"并无朱粉涂饰";蘅芜苑写"清瓦";稻香村写茅顶。
- **形制方**:`06-13` 绿琉璃用于王府及皇子居所;`06-14`(已驳倒)载亲王府"正门、寝殿均绿色琉璃瓦"。省亲别墅是元妃驻跸的行宫,按等级本可争取绿琉璃。
- **裁决**:**原文胜。全园禁琉璃**,一律灰陶:A 档筒瓦,B/C 档蝴蝶瓦,C-r 茅苫。`06-13` 整条列入 A 档禁用 id。
- **代价**:放弃了"省亲行宫"这个身份能带来的最高瓦作等级,正殿的等级感只能靠体量、斗拱踩数、走兽数、月台与白石栏杆去撑,不能靠瓦色。这是有意的——原文用"不落富丽俗套"(`07-02`)给全园定了调。

### R-07 A 档翼角:清式冲三翘四 vs 江南嫩戗发戗(层级冲突)

- **争点**:这一条**不是原文与形制打架,是形制内部两层打架**。原文对正殿/正门的翼角**没有任何描写**(`07-20` 只写"雕甍绣槛"),所以第 1 级空缺,由第 2、4 级对撞。
- **清式方**(第 2 级):`ART_DIRECTION.md` §1.5 tier 表明确写 A 档用"清《工程做法》大式";`03-09`~`03-13`、`03-16` 是配套做法。
- **江南方**(第 4 级):§5"翘角要翘(嫩戗发戗,戗角起翘明显)"是全园气质的核心。
- **裁决**:**按优先级栈,清式(第 2 级)压江南审美(第 4 级)。A 档走官式老/仔角梁 + 冲三翘四 + 椽槽;B/C 档走嫩戗发戗 + 戗山木。**
- **代价**:全园会出现两种起翘语言——主轴几座官式建筑的角**明显比园中亭榭钝**。这是优先级栈的直接后果,不是失误,**棚拍反审不得以"翘角不够翘"为由退回 A 档建筑**。若日后决定全园统一走嫩戗,那是对 §1.5 tier 表的**显式修改**,须改 `ART_DIRECTION.md` 并在本条记档,不许在构件里偷偷改。

### R-08 沁芳「石桥三港」三孔石拱 vs 江南「曲桥贴水面、桥面低」

- **原文方**:第十七回「石橋三港,獸面銜吐。橋上有亭……此亭壓水而成」。三孔券桥 + 桥上建亭,是有相当拱矢高的做法。
- **形制方**:`ART_DIRECTION.md` §5"水要有驳岸……曲桥贴水面,桥面低"。
- **裁决**:**原文胜。沁芳做三孔石拱桥 + 桥上亭,拱矢按可通采莲船与座船取**(`07-16` 采莲船 4、座船 1)。
- **代价**:§5"桥面低"那条在沁芳处失效。补偿办法:园中**其他**桥(蜂腰桥 `07-61`、蘅芜苑折带朱栏板桥 `07-17`、藕香榭曲折竹桥 `07-64`、怡红院白石横架 `07-50`)一律做低平贴水,把江南气质压在这些桥上。沁芳作为全园唯一的"高桥",反而成为水系的构图中心——这与它"沁芳泉正源"的地位一致。

### R-09 潇湘馆「小小两三间」与厅堂比例式的适用域

- **原文方**:第十七回「小小兩三間房舍」;第四十回「這屋里窄」。原文两次强调**小**。
- **形制方**:`05-02` 檐高 = 正间面阔 × 0.8,`08-08` 同式——但 `05-02` 被实测**驳倒于小型厅轩**,`08-09` 乙给的适用域是"仅 W ≈2.5~3.5 m";`05-20` 又说"厅堂宽恒三间"。直接套会把潇湘馆算成一座常规厅堂。
- **裁决**:**原文胜。取 3 间,明间面阔压到 3.0~3.2 m 档(落在 `08-09` 适用域内),`H = 0.8W` 直接可用,不启 clamp。** 全屋按"小"来配:界深取下限 3.5 尺,提栈起算三算半,脊桁 5 算(民房档)而非厅堂 7 算。
- **代价**:潇湘馆的等级读起来会**低于**它主人的身份。这是原文的安排(`07-43` 刘姥姥"这那象个小姐的绣房,竟比那上等的书房还好"——用书房而非绣房来比),保留。

### R-10 原文有物、形制无条 —— 一律 L4 直录

三处同类,合并裁决:

| 处 | 原文物件 | 形制文献状况 |
|---|---|---|
| 怡红院 | 碧绿凿花地砖、玻璃大镜、玻璃窗 + 可揭窗屉、西洋机括穿衣镜门、满墙抠槽与壁相平 | 清式/法原**均无条文**;西洋机括属舶来品 |
| 藕香榭 | "盖在池中"的水榭 | 《营造法原》第十五章有亭、廊、无"榭"的独立条文 |
| 凸碧山庄 | 山脊上的"敞厅" | `05-20` 厅堂形制表无"敞厅"档 |

- **裁决**:**原文胜,按原文字面直接建模,不去找也不去编形制依据。** 藕香榭按 `05-20` 船厅(回顶)外推;凸碧按 `05-20` 四面厅做法外推;怡红院的西洋物件按原文描述直接造型。
- **代价**:这三处的构件**都标 `confidence: L4`**,在 `scene.json` 里必须带该字段。它们不进 `src/fashi` 的推导校核链,反审时只核"是不是原文那样",不核"形制上成不成立"。**特别地,不许因为找不到形制依据就把玻璃大镜改成铜镜、把玻璃窗改成纸窗**——玻璃与西洋机括是原文点名的物件,是怡红院的性格。

### R-11 栊翠庵「山门」的寺观规格

- **原文方**:第四十一回「送出山門,回身便將門閉了」「山門外頭牆根下」。原文用"山门"这个寺观专名。
- **形制方**:`06-10` 龙吻脊"大部分用于寺庙主殿及品官府第、家祠",是苏式最高脊型;哺龙脊为"寺宇之厅堂"。若按"山门"二字直接对到寺观制度,栊翠庵会被抬到与家祠同级。但它是园内一处小庵,妙玉带发修行,规模只到"耳房待客"。
- **裁决**:**原文胜于"是不是寺",形制降级用于"多大的寺"。** 保留"山门"这个建筑类型(做门屋而非墙门,有门槛可闭),但正脊取 **哺龙脊(寺宇厅堂档)而非龙吻脊**,规模按 Tier B 住宅小式配,不做大式。
- **代价**:栊翠庵在剪影上要**同时读得出"是庙"和"很小"**,这个矛盾落在山门上——门屋做足寺门特征(高门槛、板门、门簪),体量压到 B 档。若剪影读不出,优先保"是庙"。

### R-12 大观楼/缀锦阁/含芳阁属"楼房"= 杂式,却划在 Tier A

- **原文方**:第十八回「正樓曰『大觀樓』。東面飛樓曰『綴錦閣』,西面斜樓曰『含芳閣』」;第十七回「崇閣巍峨,層樓高起……迢迢复道縈紆」;第四十回可登梯、贮物。三者都是**多层楼阁**,并有**复道**相连。
- **形制方**:`01-03` 的三分法里,楼房、钟鼓楼、垂花门、亭、游廊归 **杂式**(《营造算例》第三章),而非大式或小式。按这个分类,大观楼群应走杂式,不走斗口制。
- **裁决**:**Tier 与模数解耦。** 大观楼群 **tier 判 A**(等级、瓦作、彩画、走兽、斗拱全按 A 档),但**楼层构造**(平坐、上下层柱接、楼梯、复道)按杂式做法处理,不去 `01`/`04` 里找不存在的楼阁权衡条文。
- **代价**:①"Tier = 参数集"这条简化在本项目并不严格成立——**tier 决的是等级与做法档次,不是构造类型**,`§1` 的表须这样读;②复道(阁道)的断面、净高、坡度在 01~08 八章里**一条依据都没有**,全部 L4;③含芳阁的"斜"字原文只给了一个字,倾斜的对象(平面斜置?屋面斜?)未定,须在 `scene.json` 里显式标注本项目的选择与 L4 置信度。
