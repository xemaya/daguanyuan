## 跨章结论

### 1 斗口制与材分制的关系:同构不同源,可换算但不可互推

| | 宋 材分制(`docs/fashi/01`) | 清 斗口制(本目录 01/04) |
|---|---|---|
| 模数定义 | 材广 15 分、材厚 10 分;分=材广/15 | 平身科迎面安翘昂的斗口宽 |
| 等第 | 八等材 | 十一等斗口(6.0 寸递减 0.5 至 1.0 寸) |
| 屋面生成方向 | 举折:先定总举高,自上而下逐缝下折(H/10、H/20…) | 举架:自下而上 `y_i = y_{i-1} + k_i·s_i`,脊高是输出 |
| 斗栱计数 | 铺作(四~八铺作) | 踩(三~十一踩);江南=出参(单数) |

三条已核的换算关系:

1. **斗口值 ≈ 宋材分值 × 10**(04-10,confidence medium)。**只作跨代校验,不作生成**——同条另外两个数字被实测打掉(明间 8 攒非定律,实为 6 攒;斗拱高/柱高实测 1/6.7~1/7.5,比条文的 1/5~1/6 更小)。
2. **斗栱计数三系可通约**(05-15):`出参 N = 2×每侧跳数 + 1`;`宋铺作 = (N−1)/2 + 3`;`清踩 = N`。即三出参=宋四铺作=清三踩,五出参=宋五铺作=清五踩,七出参=宋六铺作=清七踩。其中"清踩=出参"由定义推得、原书未明写,已自标 medium-high。
3. **提栈/举架/举折三名一物**(05-27、02-11):`算 ≡ 举 × 10`(五算=五举=0.5=坡度正切×10)。江南与清同为自下而上"边举边折",宋为先定总举高再自上而下折;同一总步架条件下清制比宋制陡约 5.9%(长春宫量化验证,实测值恰夹在两者之间)。

**但换算不等于可互推**:`qingshi.schema.json` 的 mapping 段里,**模数基准、柱侧脚/生起/收分两行对 `fayuan` 一侧写 null**——江南体系没有全局模数(根参数是正间面阔与界深,斗口只在牌科内闭环),也没有生起/侧脚制度。生成器遇到 null 行必须走替代路径,**不得反折**。

### 2 清式与江南做法的分野:必须是两套函数,不是一套函数加系数

这是本目录最贵的结论,由 03/04/05 三章的乙方反复给出,并在 `verify-suzhou.md` 量化:

| 量 | 清官式北方 | 江南香山帮 | 硬套的代价 |
|---|---|---|---|
| 营造尺 | 32.0 cm(实测锚 32.16) | 吴尺 27.5 cm | **整体缩放错 16.4%**(01-19) |
| 模数根 | 斗口(大式)/ 檐柱径 D(小式) | 正间面阔 W + 界深 d;斗口只在牌科内 | 江南建筑套 D 模数会被"通进深≤7 檩"卡死(01-03) |
| 柱径 | 6 斗口 或 H/11 | 围径式,W×0.051~0.064,柱高:柱径≈15:1 | **画出"北方味"的粗柱,细瘦度差 14%~43%**(01-14) |
| 出檐 | 0.3 × 檐柱高(+拽架) | 1.5 × 出檐椽平出,**由界深决定、与柱高脱钩** | **檐挑长两三成**;实测比值 0.17~0.21H,月到风来亭实算 −30.8%(03-01、verify §D) |
| 翼角 | 老/仔角梁 + 冲三翘四 + 椽槽 | 嫩戗发戗 + 戗山木;冲出=放叉一尺定值 | "椽槽"在江南根本不存在;冲三按椽径倍数是错的量(03-09、03-16) |
| 转角斜长 | 方五斜七 1.4 | 六角需 2/√3=1.155,八角 1/cos22.5°=1.082 | **六角亭误差 +21.2%**(verify §D 结论 1) |
| 屋面坡度 | 举架系数表 5/6.5/7.5/9 举 | 提栈算,起算 `min(界深尺,5)`,常 0.35~0.45,更平缓 | 官式表硬套会把江南屋面抬陡(02 章江南边界提醒) |
| 间广递减 | 太和殿实测 次/明=0.655、梢/明=0.43 | 次间=明间×0.8 | **两体系的间广序列不可互换**(05-27 乙补第⑥条冲突) |
| 瓦作 | 大式筒瓦/琉璃,号数表 | 蝴蝶瓦(小青瓦),1 尺=275mm | 06 章按 `system` 分两组参数 |

只有**两处**南北天然对上:小式柱高 = 0.8 × 明间面阔 ≡ 江南檐高 = 正间 × 0.8(**误差 0%**,04 章最可靠的一条);清飞椽三五举 ≡ 江南三算半(0%)。

**结论**:`tiers.md` 已把 03-01、03-16 等清式条列入 Tier B/C 禁用 id;`verify-suzhou.md` 给出了禁用的量化理由。实现时北方档与江南档分成两套函数,**不要合并求平均**。

### 4 必须做参数、不能硬编码的项

`qingshi.schema.json` 里每个下列字段的 description 都带 correction 与"作参数不硬编码"标记。按危害排序:

**A 类:硬编码就整体缩放错**
1. `chi_cm` 营造尺长(01-19 存疑)。按地域取:官式北方 32.0(锚 32.16)/ 吴(苏州太湖)27.5 / 浙 27.8 / 闽 29.4~30 / 粤 31.5 / 赣 35~35.5。**差 16.4%,两档不得混用**;大观园走江南默认 27.5。`tiers.md` §0 元规则 3 另裁全项目采 0.32,凡引 05 章数值须显式标注换算档。
2. `region` 地域体系 + `style`/`modulus` 解耦(01-03 存疑、01-14)。"有斗栱=大式"的二分法被本章自身证据推翻(《工程做法》卷四~二十三是"无斗科大木"却不属小式),必须改**三分支**(大式/无斗科大木/小式)且 style 与 modulus 解耦;江南单独走 `fayuan` 分支,不套此判定。

**B 类:生成方向本身是反的**
3. `bay_cuan_counts` 各间攒数(01-05 驳倒)。攒数是**输入**不是常量,`W_间 = (N_平身科+1)×11×斗口`。
4. 柱高与开间**不得由斗口推**(04-04/06/07 存疑,偏差 +26%~+82%;verify §C.2 四档柱高全出界 +12%~+21%)。`tiers.md` §0 元规则 2:先由等级/规模定开间与柱高,**再反算斗口**,再用斗口派生断面。clamp 下界用长春宫实测 柱高=0.66×明间、檐柱净高 52.4 dk(04-04 乙区间 52~88 dk)。
5. `step_runs_chi` 各步架长(02-02 驳倒)。22 斗口是卷一单例反推,实物散布 16~40 斗口;金/脊步 19.6~20.1 dk 而檐步 39 dk 是另一量级。**任何"全部步架等长"或"总进深均分"的写法都带 30% 级误差**(verify §D 结论 3)。
6. `W_ci_ratio` 次/明面阔比(01-17 存疑)。只作 fallback;带斗科时 `bay_cuan_counts` 优先。实测两型皆不落在 0.8 或 0.857 上(0.655 与 0.95)。

**C 类:原文本身无定量,只能做自由参数 + 几何约束**
7. `juja_coeffs` 举架系数(02-05 存疑):北方官式表作默认,上金步/脊步改**区间**(脊步实测可达 1.02,取上限)。九檩两套并存(卷一 5/7/8/9 vs 营造算例 5/6.5/7.5/9),须选默认档。
8. `tuishan_rate` 庑殿推山递减率(02-12 存疑):实例落 0.10~0.30 且**方向可正可负**;"一成"出自工匠手册非《工程做法》制度。歇山收山"1 正心桁径"同为常见做法非制度(02-13),正心桁径统一取卷一 4 斗口,**不与则例 4.5 斗口混用**(差 12.5%)。
9. `chong_convention` 冲出口径(03-09 存疑):①马炳坚放样(量在正身法线,沿斜向 ×1.414)②《工程做法》(3 椽径直接加斜长)。**必须显式声明,不可把①的公式配②的例数**。
