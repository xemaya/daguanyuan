## AG1 · 檐口收头：瓦当 + 滴水（基建，一修两得）

用户第 5 条：「房顶的瓦和木架子有明显的分层，看起来质感很差。没有瓦当、滴水，很不古风。」

**现状**：屋面是三层硬撞——**带瓦贴图的实心板 → 连檐（木料）→ 椽（一排木方）**。
真构造里这两层之间是望板 + 苫背，而檐口末端由**瓦当（筒瓦头）+ 滴水（板瓦头）**收口。
**它们的活就是盖住这条缝。**

所以「分层明显」与「没有瓦当滴水」是同一件事的两面，**补上瓦当滴水两条一起解**。

**四条**：
1. **沿檐口线一排，跟着起翘走。** `building.ts` 的 `eaveEdge()` 已经在按 `halfWidth`/`lift`/`push`
   算檐口曲线了——**用同一份数据生成瓦当滴水的落位**，别另起一套（`PQ-3` 那次的教训：
   石边与沙槽两份数据生成就会错位）。
2. **瓦当与滴水相间**：筒瓦垄头是圆瓦当，垄间板瓦头是尖滴水。垄距用 `m.rafterPitch` 那一路
   的推导值，**不要新拍一个间距**。
3. **必须能合并**（`P-04`）：一栋房子四面檐口几百个，材质走 `materials.ts` 现成的 memo。
   **draw call 增量 ≤ 4。**
4. **纹样从简。** `ART_DIRECTION.md` §10「远看形 / 中看色 / 近看工」——瓦当面在视距上只有几个像素，
   做出圆形的**形**与一圈边就够，**不要刻兽面或文字**。

**判据**：`node tools/capture.mjs --shots cu_gate_eave`（AD 已有这个贴脸机位），
抬头看檐下**看不出"板压在木条上"那条缝**。

## AG2 · 格心纹样构成（基建）

用户第 2 条：「窗花目前还是很粗糙的样式。」

**现状不是"不够密"，是构成错了**。`building.ts` 的 `lanternLatticeGeometry`：

```
0.3 m 见方的均匀方格  +  每格内接一个菱花  +  0.02 m 方棂条  +  单层平面
```

读起来就是**方格纸上打叉**。真灯笼锦是**大小格相间**——大的"灯笼框"配短棂条，
节点上有**卡子花**。`07-76` ③ 已经写了三段分工（格心负责"新鲜"、绦环板与裙板负责"细雕"），
三段分工做对了，**错的是格心这一段自己的纹样**。

**三条**：
1. **加密解决不了，改构成。** 大小格相间 + 卡子花，不是把 cell 从 0.3 缩到 0.15。
2. **棂条要有起线**（断面不是方的），近景才不是一堆火柴棍；但**三角数要控**——
   `makeGeshan` 的注释写着「细于 4cm 的棂条倒角看不见，用直箱省 15 倍三角」，
   **这条仍然成立**，起线只给**格心**这一层，裙板绦环板那些细条不动。
3. **`ice`（冰裂）与 `wan`（万字）不要顺手改。** 潇湘馆用的是 `ice`，改了要重新验它。
   **本单只动 `lantern`。**

**判据**：`--shots cu_lattice` 贴脸拍，**看得出是"灯笼"不是方格纸**。

## AG3 · 垂带端面（纯 bug，最小）

用户第 7 条：「台阶两侧的斜坡……上方衔接处有一个很碍眼的三角形凸起。」

**已经算死了**（`shots/zhengmen-closeup/README.md` 有完整复算）：

```
垂带是一根整体绕 X 旋转的矩形盒,端面跟着转成斜的
→ 上端翘出台基面 12.9 cm 高 / 28.9 cm 长 / 24 cm 宽
→ 下端本该入地 4.9 cm,但门前地面外倾,实际悬空
→ 内侧面 ±1.48 m 与踏步边 ±1.50 m 搭接 2 cm,**不是缝,不用改位置**
```

**做法**：垂带石两端**竖直切**（做成梯形棱柱，不是转过来的方盒），
下面那个三角形是**象眼**，**要填实**，不是让石头翘出来。
`slope + 0.12` 那截余量**去掉**——本来就该在台基边收住。

## AG4 · 匾额宽度按开间算（纯 bug）

用户第 10 条：「大观园的牌匾，不够大气，不应该和潇湘馆一样大的。」

**根因一行**：

```ts
const pw = Math.min(2.0, Math.max(1.0, opts.plaque.length * 0.45));
```

**匾宽是"字数"的函数。**「大观园」与「潇湘馆」都是三字 → **都是 1.35 m**，用户看得分毫不差。
实测当心间 **3.276 m**（`columnX ±1.638`），1.35 ÷ 3.276 = **0.41**，常规是 0.6–0.75。

**做法**：`pw` 改成**当心间净宽的函数**（比例是艺术选择，留 `provenance.art`）；
**字数只决定字有多大**，不决定板有多宽。`makePlaque(text, width)` 的签名不用改，
改的是调用处怎么算 `width`。

**⚠️ 两条**：
1. **月洞门那块匾（`wall.ts:802` 的 `makePlaque(plaqueText, 0.95)`）也要跟着讲道理**——
   它挂在月洞门上，"开间"就是门洞宽。别让一个改成按开间、另一个还是写死 0.95。
2. **匾额挂点已经变了。** 单子 V3 把斗拱装上去之后 `m.puzuoH` / `m.puzuoOut` 都变了，
   匾额位置是从它们推的（`yMid` / `zFront`）。**先看一眼现在挂得对不对，再改宽度。**
