## AT1 · 匾额

**现状**（`plaque.ts` 60 行 + `building.ts:1735`）：黑漆 `roundedBox` 一块（厚 0.06）、金字、四条细金条当边；宽 = 当心间 × 0.62（≈ 2.03 m），高 = 宽 × 0.36；
字用 `bold STKaiti/KaiTi` 系统字体，三字右起横排；平贴在额枋上，不倾、无托、无款。**它读成「牌子」的原因不是尺寸一件事，是五件事一起缺。**

| 缺的 | 做法 | 出处 |
|---|---|---|
| **字不古朴** | 换成**榜书感的毛笔楷**：内置一款 OFL 字体（首选 Google Fonts 的 **Ma Shan Zheng**，其次 Long Cang），**文件放 `public/fonts/`、`@font-face` 本地加载**（不依赖外网），canvas 画字前 `document.fonts.load` 等字体就位再画；字号顶到匾心高的 0.78；金字加**双层描边**（外圈深金、内圈亮金）模拟贴金厚度 | 字体选择是艺术选择（`provenance.art`）；清代匾多楷书榜书，无具体出处 |
| **边框太薄** | 真匾框：**外框 木质起线两道 + 内一圈素边**，框宽 = 匾高 × 0.09，框厚 0.05 高出匾面；四角**如意/云头角花**（简单挤出，§10 具象要集中——只在四角） | 形制常识，乙待核 |
| **平贴** | **前倾 12°**（上沿离墙，下沿贴），两只**匾托**（铁钩形，从额枋下挑出，深色金属）——前倾是匾"挂"出来的最强信号 | 清式匾额挂法，乙待核 |
| **无款** | 右上小字上款（省亲别墅之类**不写**，`07-01` 正门匾只有「大观園」三字），**只加左下一方朱红钤印**（1/12 匾高的方章，内刻两字小篆或留素红方块）——落款文字**不编** | 钤印是匾的通式；不编款是 `D-05` 原文最高 |
| **小** | 宽从当心间 × 0.62 抬到 **× 0.72**，高 = 宽 × 0.40；**先出一档对照**（0.62 vs 0.72）给用户看 | `A4` 说过匾宽是开间的函数，系数是艺术选择 |

**判据**：`cu_gate_plaque` 贴脸 + `gate_approach` 中景各一张，前后对照；字读得出笔锋、匾有厚度与前倾、四角有花、左下有印。
**预算**：`gate_approach` ≤ +0.5%（都是小件），draw call ≤ +3（金属托、印章材质各一桶）。
**字体文件**：必须是开源授权字体（OFL 等），写清授权协议与来源 URL 到 `public/fonts/README.md`；不许用没有授权或授权不明的字体。
**硬性中断点**：0.62 vs 0.72 两档宽度对照图出完即停手，不许自行拍板选一档往下做；把两张图和推导发给用户，等用户选完再继续 AT1 剩余步骤（边框/前倾/钤印等其余四件事不受影响，可与出图并行先做）。

## AT2 · 抱鼓石挪到踏跺两侧（垂带抱鼓）

**用户拍板**：抱鼓石不在门道里，放**台阶两侧**。

**形制对应**：清式踏跺的**垂带石下端**常设抱鼓石（垂带抱鼓 / 砚窝石一带），鼓面**朝踏跺**、左右相对，坐在踏跺脚的地面（这里是台矶面层）上——正是用户要的位置。
甲核：这是通式；乙待核：《工程做法》踏跺垂带条目有无抱鼓规定（记 `07-honglou.md` open_questions，与 AJ2 那条并排）。

**做法**（`composer.ts` `baogushiSpotsFor`）：
- 落位从「中柱缝门框内侧」改为**前踏跺两条垂带石的下端外侧**：x = 踏跺半宽 + 垂带宽 + 鼓厚/2 + 0.03；z = 垂带下端（台矶面层上，踏跺脚）；y = 台矶面层顶；
- **朝向**：鼓面朝踏跺中线（左右两块互为镜像，`sign` 已支持），门枕石那截**去掉**（不再跨门槛，构件变体 `'chuidai'` 或参数 `withPillow:false`）；
- 须弥座落在面层上要与 AJ1 的墁缝网格对齐（座边压在缝线上或整块内，别骑缝）；
- 碰撞中心随之改（`baogushiSpots` 的 `dx/dz`），`playtest` 脚下序列不许在踏跺脚出现绊脚。

**判据**：`cu_baogushi` 机位改到踏跺脚（只追加/修改这一个机位），正面看两块鼓在台阶两侧、鼓面相对、不在门洞里；`gate_approach` 里门道干净。
**预算**：三角不变（同一个构件），draw call 不变。
