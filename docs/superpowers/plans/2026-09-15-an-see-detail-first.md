## AN1 · 后期单变量对照：是什么在糊掉雕刻

**现状**：`PostFX.settings.grain = 0.016`，`grade.ts:33` 在 ACES 之后、sRGB 编码**之前**加均匀噪声——
线性域加噪，gamma 把暗部放大，所以贴脸图暗部是整片蓝颗粒。GTAO `radius 2.4 / scale 1.15` 也在同一条链上。
**不知道是哪一层把斗拱和雕刻糊掉的，就不要动任何一层。**

### 做法

1. `PostFX.ts` 加三个只读 URL 的评审开关（照 `?dof=` 的写法）：
   `?grain=<0..0.03>`、`?ao=off|on`、`?aoscale=<x>`。**默认值一个不改。**
2. `builder/parts/materials.ts` **不碰**。材质法线的强弱对照用 `?normalscale=<x>` 在 **`engine`** 侧统一乘
   （找到材质登记的公共出口；找不到就只做前两组，回报里说明）。
3. 同机位拍四组，每组只变一个量，其余全默认：

   | 组 | 变量 | 机位 |
   |---|---|---|
   | G | grain 0 / 0.008 / 0.016（默认） | `cu_baogushi`、`cu_gate_eave`、`cu_lattice` |
   | A | ao off / on（默认） | 同上 |
   | S | aoscale 0.7 / 1.15（默认） | 同上 |
   | N | normalscale 0.5 / 1（默认） | 同上（能做的话） |

   用 `tools/side-by-side.mjs a.png b.png out.png 标签A 标签B` 出左右对照，每组每镜一张。
4. **量一个数**：每张图取一块**平坦暗部**（例如 `cu_baogushi` 左下青石踢脚 200×200 像素）的亮度标准差，
   写成表——「颗粒 0.016 → 0：暗部 σ 从 X 到 Y」。评审只靠眼睛就会又被静帧骗一次。

### 判据

- 对照图齐（≥ 9 张 side-by-side），暗部 σ 表齐；
- **一个默认值都没改**——改值是用户看完对照后拍板的事（`D-02` 动森式、`ART_DIRECTION` §4，颗粒是 look 不是 bug）；
- 回报里写清**你**认为是哪一层把雕刻糊掉的，以及**你建议的档**，但停在建议。

### 回报

开关怎么接的；四组对照图路径；σ 表；建议档与理由。
**规模**：小。**风险**：低。最容易跑偏：顺手把 grain 改成 0 提交——不许。

## AN2 · 材质加工尺度：三档信息，重点补厘米层（等 AJ 合回）

评审 §5 的表是题面。现在白石与青石共用一套各向异性凿痕（`materials.ts:252/293`，`u*5, v*0.4`），
粉墙的潮痕烘在可重复的 v 里（`materials.ts` 第 91 行「v=0 是墙脚」）。

### 做法

| 材质 | 改什么 | 不改什么 |
|---|---|---|
| **白石**（`whiteStoneMaps`） | 拆成两档：**细磨面**（各向同性弱颗粒、低幅法线、粗糙度 0.55 一档）给鼓面、台面、阶条石；**粗档**（保留凿痕）给鼓帮、座脚、陡板石。两档各自一个 `Maps`，构件按部位选 | 色相（07-01 暖白）不动 |
| **青石**（踏面） | 大面平整，凿痕幅度降一档；边缘圆磨靠几何倒角不靠贴图 | 苔斑保留 |
| **粉墙**（`plasterMaps`） | **潮痕从贴图 v 里拿出来**：贴图只留抹灰起伏与砂感；潮痕改由 `wall.ts` 按**构件局部高度**写顶点色（或第二套 uv），墙脚 0–0.45 m 淡出，与 repeat 无关 | 墙的几何、压顶、洞口一个不碰 |
| **木作** | 木理沿构件长轴；端面另给一张小贴图 | 这条**只做材质侧**（`woodMaps` 出端面变体），构件侧改 UV 归 AP / 各构件自己 |

每种材质在文件头注释写清**三档尺度**：米级色块 / 厘米级加工 / 毫米级微表面，各自的贴图覆盖多少米、法线幅度多少毫米。
**老化克制**：不加裂缝、剥漆、碎瓦。

### 判据

- `cu_baogushi`：鼓面细磨、鼓帮粗，两档肉眼分得出；
- `xiaoxiang` / `moon_gate`：白墙**没有横向色带**（潮痕不再随 repeat 循环）；
- `gate_approach`：台面不再是一块「塑料板」（与 AJ1 的砌缝叠加后看）；
- `D-25` 四镜 ±3%（材质改动不该动三角；draw call 若因两档白石多一个材质桶而 +1~2，如实报）。

### 回报

每种材质三档的数；潮痕搬到哪里、怎么算的；对照图；预算前后。
**规模**：中。**风险**：中——**最容易做过头**（把贵族园林做成废墟）；**潮痕搬家最容易漏**某一类墙（院墙/侧墙/门屋槛墙走的不是同一条路）。
