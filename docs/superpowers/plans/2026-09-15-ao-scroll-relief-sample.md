## 现状

`forecourt-terrace.ts:48` `ridgeTube`：一条 `CatmullRomCurve3` 拉 `TubeGeometry`（半径几毫米、6 段），叶子是压扁的球——
从 `building.ts:202` 原样抄的。评审与截图都说它读成**粘上去的铁丝**。文件注释自己写着「台矶周长远大于门屋台基，卷草带原样复制会让三角预算……」。

## 做法：一份纹样，两种输出，同一个 h(u,v)

### AO1 · `pattern2d.ts`：纹样描述

不是画图，是**数据**：
```ts
interface ScrollPattern {
  spine: [u, v][];            // 主藤中线(单位化到一个纹样单元 [0,1]×[0,1])
  spineWidth: (t) => number;  // 主藤宽度沿路径变化(收尖)
  leaves: { outline: [u,v][]; vein: [u,v][]; }[];   // 卷叶封闭轮廓 + 主脉
  margin: number;             // 纹样离带边的留白
}
```
西番草一个单元 = 一段 S 形主藤 + 两片反向卷叶。**只做这一种纹样**，参数化到能出 3–4 个不重样的单元（seed 控制卷叶开合与主藤振幅）。
纹样的史料状态沿知识库（`07-76`③「西番草」有原文、样式无出处），新增形式记 `provenance.art`。

### AO2 · `relief.ts`：从纹样出高度场 h(u,v)

- 主藤：到 `spine` 折线的有符号距离 → 圆凸截面（中高边低，不是圆管）；
- 卷叶：点在 `outline` 内 → 叶面高度 + 沿 `vein` 一道浅槽；叶缘 2–3 mm 软过渡回石面；
- 分区高低：主藤最高（4 mm），叶面次之（2.5 mm），石面 0；
- **纹样边缘缓缓落回石面**——这句是「粘上去」与「刻出来」的分界。

**同一个 h(u,v) 喂两个消费者**：
1. **近景几何**：带状网格（沿带 1 cm 一格、横向 12–16 格），顶点沿法线位移 h，`computeVertexNormals`；带的两长边高度钉 0。
2. **中景贴图**：`bakeNormalMap({ size, height: h })` + `bakeScalarMap` 出凹槽遮蔽（TextureLab 现成，`recipeKey` 带 size）。
   贴在一块**平的**带状面片上，颜色仍用白石 fine 档。

### AO3 · 样件落位

**只换一段**：正门台矶前檐、台阶右侧那一段陡板上的卷草带（约 1.5–2 m 长），近景几何版；
其余各面的 `ridgeTube` **原样保留**（对照用；铺开等 AQ-b 距离档）。
同一段再出一个**贴图版**（同一份 h），挂在 `?relief=tex` 开关下，评审用。

### AO4 · 三档证据

| 距离 | 机位 | 要证明什么 |
|---|---|---|
| 贴脸 0.6 m，正视 | 新加 `cu_scroll_front` | 读得出叶面、主脉、主藤收尖 |
| 贴脸 0.6 m，斜 60° | 新加 `cu_scroll_oblique` | 读得出浮起（轮廓线有起伏） |
| 中景 6 m | `gate_approach` 那个距离 | 几何版 vs 贴图版 **pixel diff 均值 < 2 色阶**（`tools/pixel-diff.mjs`）——证明中景可以换贴图 |
| 侧光 | 现有太阳角固定，用斜机位的阴面/阳面读凹槽 | 凹槽处有暗线 |

**这三档的数据是 AQ-b 距离档的开工依据**：几何版在几米以内值得，几米以外贴图版看不出差。

## 预算

- 样件几何 **≤ 40k 三角**（1.5 m × 0.12 m 带，1 cm 格 ≈ 150×14 顶点 ≈ 4k 三角，余量给叶片加密）；
- `gate_approach` 相对基线 **≤ +1.5%**，draw call **≤ +2**；
- 贴图两张 512²，走 Worker 预热链（`texture-jobs.ts` 登记）。

## 判据

- 三档对照图齐、pixel diff 数齐；
- `C4` 那句「读成铁丝」在 `cu_scroll_front` 上不成立（验收人看图）；
- 九道门 + `playtest` PASS；`D-25` 四镜在限内；
- `pattern2d.ts` 有测试：同 seed 同输出、纹样不越 margin、h 在带边为 0。

## 回报

纹样参数、h 的分层数、几何版三角数、贴图版尺寸、三档图路径与 diff 数、**你判断几米以外可以换贴图**。
**规模**：中。**风险**：中——**最容易做成贴片**（叶子一片片贴上去，边缘硬）；**最容易顺手铺满**（不许，只一段）。
