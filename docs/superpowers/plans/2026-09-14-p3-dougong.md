```jsonc
{
  "id": "C-dg-lu", "name": "大斗(坐斗)", "paramSet": "qing",
  "attachTo": { "parent": "平板枋", "position": "正心中线上，斗口迎面安翘昂" },

  "dimensions": ["01-18", "04-03"],
  "source": { "book": "清工部《工程做法》", "location": "卷二十八",
              "quote": "大斗壹个，每斗口宽壹寸，大斗应长叁寸，宽叁寸，高贰寸。斗口高捌分，斗底宽贰寸贰分，长贰寸贰分，底高捌分，腰高肆分。" }

```

> ### 三个阶段，各自一个提交

> #### V1 · 把数从原文抬进规则表（**不做几何**）
