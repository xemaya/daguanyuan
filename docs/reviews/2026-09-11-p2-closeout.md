## 这次修掉的具体问题

1. **寺院地基被旧路抬土埋住。** 旧14站环路只在原四区及15m边界保留地形影响，外侧8m淡出，完整旧折线仍保存。寺院采样点高度从3.045m恢复到2.2m，没有抬高寺院来掩盖问题。
2. **远景只是点位。** 五组现在能生成模型；栊翠庵引用既有三栋建筑和同一围墙，不另造一份规格；P4装配时应选择一个表现层，避免同时实例化近景与远景副本。
3. **古建与自然物脱离实际地面。** 远景台基使用真实高度场采样并向下补石基；树按实测冠幅预留，未横向压扁树冠凑边界。
4. **院墙一落线就暴露穿墙路线。** 怡红院改由东桥外绕到南月门、穿堂后经独立院门出院，再从墙外转回；正门东翼粉墙及沁芳池栏的路线冲突同时消除。新增检查会拒绝未留足净口的围护线交叉。
5. **洞顶下坡压入船行净空。** 延长上部承载面，末段改成明确尺寸的石阶；路面、岩体余厚、船行空间分别核对，不填掉河床。
6. **墙、篱、廊仍被点替代。** 两溜青篱分别成线；暖香夹道有两墙和正门支路开口；月洞门唯一依附墙线；驳岸只在选定池岸布置，未把所有自然岸机械围成石墙。

- `npm run check:p2`：检查本期几何与施工输入。缺建筑规格、点占位线性对象、缺远景模型配方、失效引用、越界包络、穿墙路线、洞顶净空冲突均失败。
