# P2 路径院墙与真实月洞门

状态：本段实现、网格专项、14镜及最终完整现有游线通过。P2整期仍未完成。

## 可见变化

潇湘馆原9段旧平移院墙被一条190m的闭合墙线替代，围合为正房、退步与西廊预留空间。月洞门从旧实景(-105.8,105.1)移至plan登记的(-105,120)，与正房之间有了实际前院。门外可以看到竹丛、院内路径与小三间；正式框景关系仍由PE验收。

院墙轮廓是P2艺术施工选择，不冒充原著尺寸。内外转角由同一折线推导；两组漏窗模块与月洞门用插入件表达，改变墙段长度不会拉伸门窗。

入院路径改为从院墙南侧绕过东角，对准月洞门后直行跨槛，再入正房。plan的控制折线也相应绕墙并通过真实门位；参观后返回原门的规划线已给出，但完整29节点巡园仍未完成。

## 工程能力

- `builder/plan/wall-path.ts` 编译直墙段、凸/凹转角、门窗位置与碰撞。路径自交、回折、门窗重叠、靠拐角太近或剩余墙段过短均拒绝。
- 普通直墙按实际长度生成，优先复用6m标准段；端部在共同斜接面相遇。压顶取消内部端头外挑，端瓦短过渡让接缝高程一致；中段仍有真实瓦垄起伏。
- 墙体几何与碰撞共享门洞、门槛与墙脚尺寸。圆门按高度分层取保守净宽，不用一个从地到顶的矩形缺口冒充圆形。门槛是可行走平台，不作为挡住跨槛的立面。
- 当前编译结果：36段、13种几何原型、6转角、85个墙体盒与6个角部圆碰撞、1个门槛平台。
- 复用既有静态合并/实例化。首个未合批的内部样板为457次棚拍调用，合批后61次；两者均564,760个提交三角。这是绘制组织优化，不是宣称整体帧率提高同样倍数。
- 植被遮罩直接读取同一plan墙线，避免草与树干从新墙脚穿出。完整建筑占地预处理仍属P4，未用这项局部避让冒充全园占地系统。
- 世界合并后保留线性构件id、原始路径、插入件与计数，capture/棚拍manifest保存这些信息。原位与额外Placement变换不能重复叠加。
