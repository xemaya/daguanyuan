## 第一梯队 · 纯 bug，与观感正交，随时可做

| # | 条目 | 根因 | 大小 | 依赖 |
|---|---|---|---|---|
| A1 | **引泉沟 4.8 m 沙疤** | 浅滩沙带用固定米制常数（±2.0/2.8 m），按池岸标定却作用到 0.80 m 的沟上。**同文件 40 行外的 `warp` 已按 `inradius` 收放过，`sand`/`wetBand` 没有**。见 `P-20` | **很小** | 无 |
| A2 | **正门垂带三角凸起** | 垂带是整体绕 X 旋转的矩形盒，端面跟着转斜，上端翘出台基面 **12.9 cm 高 / 28.9 cm 长 / 24 cm 宽**；下端本该入地 4.9 cm 但门前地面外倾，实际悬空。**内侧面与踏步边搭接 2 cm，不是缝，只需改端面**（改成两端竖直切的梯形棱柱，下面三角形做成填实的象眼） | 小 | 无 |
| A3 | **抱鼓石站在当心间外** | 摆在 `lx = ±2.0`（相距 4.0 m），实测当心间只有 **3.276 m**（`columnX ±1.638`）→ 每块在柱线外 **36 cm**，且立在台基外的地面上，不在门口 | 小 | 无 |
| A4 | **匾额宽度按字数算** | `pw = min(2.0, max(1.0, 字数 × 0.45))`。「大观园」与「潇湘馆」都是三字 → **都是 1.35 m**。1.35 ÷ 当心间 3.276 = **0.41**（常规 0.6–0.75）。**应当是开间的函数，字数只决定字多大** | 小 | 看 `V3`：斗拱一换，`puzuoH`/`puzuoOut` 变，匾额挂点会自己挪 |

## 第三梯队 · 基建，全园受益（做完四区之外也吃到）

| # | 条目 | 根因 | 大小 |
|---|---|---|---|
| C1 | **墙一段段拼、接缝错位** | 六段独立 `wall` 构件，`flushEnds:false`：①墙基/压顶各端外伸 2/8 cm 对撞；②沉深噪声按**段内局部 x** 取样 → 墙脚高度在接缝处跳变；③`cloud` 波顶撞平顶；④UV 每段重置。**修法已在仓里**：`wall-path.ts` + `flushEnds:true`，只需把沉深噪声改成按**路径弧长**取样 | 中 |
| C2 | **檐口没有收头（无瓦当滴水）** | 屋面是「带瓦贴图的实心板 → 连檐（木）→ 椽（木）」三层硬撞，中间少的正是瓦当 + 滴水——它们在真构造里就是盖这条缝的。**一修两得**：既治「分层明显」也补「不古风」 | 中 |
| C3 | **格心纹样构成错** | 灯笼锦做成了**均匀方格 + 每格一个菱花**（cell 0.3 m、棂条 0.02 m 方条、单层平面），读成方格纸打叉。真灯笼锦是**大小格相间 + 卡子花**。**不是加密能解的** | 中 |
| C4 | **西番草成了一根细铁丝** | 台基侧面的卷草是压出来的细线，不是「鑿成」的浮雕。近景下读成划痕。依据 `07-76` ③。注意 `ART_DIRECTION §10`：具象雕刻要集中不要摊开 | 小中 |
| C5 | **占位没有唯一真源（`99-25`）** | `vegetation.ts` 的 `FOOTPRINTS` 是手抄的第二份真源。**潇湘馆一丛 `grove` 在 (−93.9, 98.6)，离东墙 2.90 m，而 grove 竹竿展开半径约 3.0 m → 穿墙**（图上竹竿插在白墙中段，墙脚漏出土丘）。单子 R 只重摆了落进房子的三丛 | 中 → 接缝 ③ |
| C6 | **散置不按区吃料** | 三处同病：正门「门前古松，门外净空，不作密植」（净空框只有 9×10 m，区却 80×24 m）；潇湘馆「兩邊翠竹夾路」没落地、满地大白野花是通用散布器撒的；沁芳「绕堤柳/隔岸花」在 `plants` 与 `REGION_TREES` 里都有但**区被水填满、远岸已出区吃兜底树种** | 中 → 接缝 ② |
| C7 | **引泉沟石压边（`PQ-3`）** | `builder/parts/pudi/` 现在只有 `luya.ts`。**必须排在 A1 之后**——先收沙带再描边，否则硬直线石边会浮在 4.8 m 沙槽中间 | 小中 |

## 建议的做法顺序

```
A 梯队(纯 bug)           ── 随时,互不依赖,A1 最小
   │
AD(验场门) ─► Y(区清单) ─► B 梯队随 Y 一起落
   │                         │
   │                         └─► C5/C6 归 Z(接缝②③)
   │
C1/C2/C3/C4 基建 ── 与 Y 正交,可并行;**建议先做**,
                     做完潇湘馆与沁芳你没提的一半问题会跟着好
   │
D 梯队 ── 最后。D4 的五步顺序见 qinfang.md §7:
          拱桥构件 → 桥亭 → 收窄水面 → 删曲桥重画游线 → 种堤柳
```

**两条纪律**：

1. **C 梯队（基建）先做。** 它们做完再让用户走一遍，反馈会更准——
   现在很多"这里难看"其实是同一个基建缺口的多处症状。
2. **D 梯队等 `AD` 的形制断言（第五档）立起来再做。** 但**断言本身要等 D 做完再焊**
   （`feedback`「观感迭代期不要加门」）——先修，再焊，不要反过来。
