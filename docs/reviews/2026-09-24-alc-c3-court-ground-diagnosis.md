# AL-c c3 诊断：潇湘馆院内为什么读成草坪（2026-09-24）

单子 AL-c c3「先诊断，后动手」的那张表。AL-b b5 把院内三叶草 992→127、杂草 183→41 之后画面几乎没变，
AL-b 猜「亮绿来自地形 splat 本身」但没量。这里量了。

## 怎么量

- **机位**：`xx_court_gaze`、`moon_gate`（判据两镜）加 `cu_xx_path`（贴脸，只看不判）；与 `capture.mjs` 同一个冻结
  （`fixedTime = 10`、风钉死）、同尺寸 1600×900。
- **院内可见地面掩码**：同一相机再渲一遍，地形与地被（`Grass_* / Clover / Weeds_* / Litter_* / Moss_patches / Flowers_* / FlowerBed_*`）
  换成按**片元世界坐标**着色的平涂材质——院墙多边形（两块矩形之并）内品红、外青；竹、房、灌木、路牙用原材质照常遮挡，
  地被的 alpha 裁形带过去（草叶不会变成实心方片）。再在真实画面里剔掉饱和度 < 0.12 的像素（石子漫是灰的）。
- **明度** = Rec.709 亮度（sRGB 值上算）；色相 / 饱和度取掩码内平均色的 HSL；**土色** = 色相 5–45°、饱和度 > 0.25。
- **院外同距离草坪**：同一眼高、同一俯仰，在院门外背身朝南拍（`(−105,126)` / `(−105,122.4)`，yaw π）；
  两张图**按行**对齐（平地上同一行 = 同一距离），剔掉土路（色相 < 50°），按院内每行的像素数加权求比。
- 关掉的办法：实例层用 `material.visible = false`（`visible` 会被距离剔除每帧改回去——第一轮就这么量成了「关了没变化」）；
  着色器两项是临时改 `builder/compose/nodes/terrain.ts` 一行、拍完即撤。

## 病在哪

- **不在实例层**：三叶草、杂草关掉，平均色一位不动（AL-b b5 压草株数达标、画面没变，就是这个原因）。草丛实例
  比它脚下的地**更暗**，关掉院子反而亮 2–5%。
- **在地形着色器的草皮层**：换成土，饱和度 0.33→0.07、0.40→0.14——院子那层「绿」几乎全是草皮贴图（乘了偏蓝的
  `lushTint`）给的。苔混合只把院子压暗 8–9%、色相往蓝偏 13–16°，苔色（线性 0.115/0.175/0.075）太淡、与草皮太近，盖不住。
- **院子并不比院外亮**：同行比已经是 0.86 / 0.82。「读成草坪」读的是**色**（偏蓝的饱和绿 150–165°）与**纹理**（剪过的草皮），不是亮度。

## 另一件量出来的事（文件域外）

院内大半在竹与粉墙的影子里，影里只有天光（蓝）照着：**把苔量拉满、苔色给成暖橄榄（sRGB 色相约 53°），
画面上的平均色相是 171–184°（青）**（临时把浓苔档增益调到 10 拍的）。在现在的光照下「更暗」就是「更蓝」，
只改地表反照率把屏幕色相推向橄榄推不动——要推，得动天光 / 环境光的颜色（`engine/render/Atmosphere.ts`），不在 AL-c 的文件域。
