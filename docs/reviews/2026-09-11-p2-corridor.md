# P2 潇湘曲廊与跨溪连接

本段交付54m曲廊、10m跨溪石栈桥及对应的地形/碰撞连接。P2整期尚未完成。用户最新要求：完成P2并验收后停止，不推进P3、PE、P4、WG、PX、P5。

## 可见变化与施工契约

- 潇湘西廊由四段折线生成，长度10/10/24/10m。20间、42根实际柱子，三个转角各共用一对柱，不叠柱。柱网与断面来自法原推导；屋顶与石质廊面连续斜接，端部有真实厚度。尺寸侧样为显式艺术输入，不作为原著实测。
- 廊面为凹多边形平台，碰撞只覆盖真实地板；矩形包围盒中间的空院子不会出现悬空地板。植物避让使用同一廊面边界。
- 翠嶂西口原道路整地曾把溪水填成陆地。保留河床后实走暴露断路，现增加10m石栈桥与北岸落脚面。桥面标高2.6m，桥下河床保留-1m；五组桥墩底部按真实地形采样，横梁/栏杆跟随桥向。此桥是工程补充，不声称原文点名了一座桥。
- 新桥的接岸高程固定到桥面，削高岸而不抬河床，外侧4m羽化；总落脚面增至16处（11陆地、4跨水、1港洞），新桥自身平台另由桥spec产生。
- 材质缓存按是否使用顶点色分开，消除墙/旧桥修改共享材质模式影响其他网格的风险。
- 不超过64m的曲廊/新桥将静态原型合为单簇；190m院墙继续空间分簇。曲廊棚拍37→19 calls，34,524三角保持不变。实例矩阵逐值测试覆盖正负坐标跨格情况。

## 边界与后续

完整曲廊巡行是通行验收支线，不加入第十七回主线的叙事里程；原文仍是入院至正房、再后院。`playtest.mjs` 当前验证正门至潇湘馆及曲廊，不是全园29节点游线。

河岸与窄沟仍有高差偏大、土坡露面明显的观感问题；局部水位、驳岸和叠石细化留在既有后续阶段。单值高度场也不能表达真正石洞顶板，现有绕山路不冒充完成原著石洞关系。

P2剩余按原架构spec §8及ROADMAP逐项核对：12项建筑规格、29节点站/节点/景数据及连接、五类未入远景、其他线性构件。P3拥有真斗拱、分层梁架、楼阁与乡野构件几何；P4拥有整园分区装配。完整世界实走与规划几何必须分别报告，不能把未建设区域的规划线称为已验收实景。
