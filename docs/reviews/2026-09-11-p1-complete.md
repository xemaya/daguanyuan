# P1 收尾验收

以任务E的1d7cb2c9、任务F的2bf7420c为基础，补齐环境坐标与重复构件实例化。本报告只关闭P1；P2及之后仍未完成。

## 交付

- 地形发布实际采样域，水从同一域取池底高程；不再使用旧原点附近的水深贴图，也不在窗口之外生成默认海洋。当前水深图540×432，覆盖270×216m，沁芳池采样约1.37m深，与实际地形约1.34m相符。
- 恢复146棵自动背景树，连同7棵既有景观树，共153棵；全部在当前域内，153个树干碰撞登记齐全。新林丛让开路线与既有景观树，不改路线与建筑锚点。
- 太阳阴影跟随玩家，光空间按texel对齐；四区玩家及身边构件均在阴影覆盖内。阴影从VSM切到PCF，消除了实际墙面上的条纹，依据见DECISIONS D-23。
- 修正仍开启的窗纸transmission=0.35，恢复P-05规定的标准材质加少量emissive。法线/深度通道复用已生成阴影，运行时确认每帧只有一次阴影生成。
- 49份重复静态子网格复用6组几何原型，按空间格实例化；保留对象父级变换、阴影属性和顶点色。植被也共享不可变的原型顶点/索引，实例矩阵、颜色及风数据分别维护。
- 风动包围余量从实际aFlex、aWind与材质风幅推导，覆盖支持的最大风强度。三机位视锥开关对照未出现可见内容差异。
