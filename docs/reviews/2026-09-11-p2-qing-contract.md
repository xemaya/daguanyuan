# P2 清式施工规格与骨架

本段补齐正门、正殿、大观楼、缀锦阁、含芳阁的施工输入，生成5份主规格及3份上层规格。它们是可执行的P2骨架契约，不是已建成的P3模型。P2整期仍未完成；用户要求完成P2并验收后停止。

## 具体改动

`projects/daguanyuan/plan.json` 的五项清式对象声明面阔、逐步进深、柱高柱径、斗口、斗科总高、平板枋、台基及收山输入。全部尺寸是显式艺术选择，不声称原文或实测给出了这些值；原文形制及待裁决项单列source/finish。

`builder/derive/qing/building.ts` 编译实际清式骨架并附带输入出处。尺寸缺失、非法踩数、不成立的净空或楼层位置直接失败。现有P1调用方式继续保留；新项目规格不再消费04-04/04-07的存疑总尺度比例，也不使用缺失的斗口反算99-02。斗口仍驱动椽、额枋与出跳等构件断面。

三座楼阁声明上层缩进、楼面标高及下层屋面模式：大观楼为需开口的下檐，东西阁下层不另设完整屋顶。校验拒绝把两座完整单层房屋直接摞起来。P3还需真实层间连接、楼梯、斗科和下檐开口几何，本段没有宣称结构施工验收已完成。

五项都标为frame-ready。项目模型入口遇到它们明确拒绝，并指出P3几何未完成；不会套法原或宋式房屋兜底。已有20项法原模型入口保持原行为。棚拍清单现在报告32项总数、可拍20项和12项未完成几何，其中5项骨架可用、7项缺spec，避免选择性PASS掩盖缺口。

- 删除显式尺寸、给负开间、非法踩数、让上层不缩进、把楼面插入下层或声明完整下层屋顶，校验均拒绝。

## 明确保留的形制选择

正门原文没有指定硬山或歇山；本段保留plan的硬山，记录它与tiers预设歇山不同。泥鳅脊按既有R-02声明低平圆脊、无翘头，专用几何未完成。正殿沿用plan的歇山侧样；此处不能被解读为已实现tiers预设的重檐构造。含芳阁目前仍朝南，原文“斜楼”的角度是未定艺术选择，未伪造原文角度。
