# P2 法原施工参数与两处实景接入

状态：本段实现与最终构建验收通过。P2整期仍未完成。

## 可见变化

沁芳亭由旧宋式材分预设改为方亭柱网：柱心见方3.3m，无宋式铺作，檐口与戗角消费《营造法原》推导。台基仍为0.4m，桥向开口保持畅通。

潇湘馆由旧歇山预设改为plan中的卷棚硬山小三间，面阔9.6m、柱心进深6.72m。屋顶取消正脊，顶部以双脊桁及切线连续圆顺曲面收合。台基仍为0.45m，建筑锚点不动。

这两个尺寸是P2显式施工选择，不是原著给出的实测值。它们连同尺长、柱础、檐部连机高度、椽中距、收山与卷棚侧样参数，完整写进plan和provenance.art；营造规则本身没有补写虚构数值。

## 构件与数据能力

- 20项单体江南建筑具备可执行施工输入：3座方亭、17项厅房/门屋。项目工厂按稳定id从plan读取，通用builder不导入大观园数据。
- `fayuan` 的tier与form分开。Tier C厅/廊须显式给柱高，不能套用住宅檐高或亭柱比例；短进深若不在六界算例内，必须显式给各界算数并记艺术来源。
- 方亭的柱网由方形平面几何落为四柱；多边形亭未接几何时直接拒绝，不能悄悄变成四角亭。
- 法原建筑不叠加宋式普拍枋及铺作；柱础与檐部承托高度由施工输入闭合，不再把P1的零值当作可建成尺寸。
- 卷棚侧样把单脊桁改成对称双脊桁，顶面圆顺过渡，不让被截低的屋面穿过原来的中心脊桁。
- 藕香榭按“四面有窗”增加两侧和后面的窗墙，正面有门及两侧窗。不是用普通敞厅预设冒充。
- 棚拍支持 `garden-building:<稳定id>`。未知建筑预设、缺施工spec及非木构对象均拒绝，冒号后的变体参数完整传递。
- 构件元数据保存施工spec、尺寸、表面配置、规则出处与原文条目。世界静态合并后，Garden仍保留各栋建筑记录；capture与棚拍manifest写出这些信息。
- 棚拍缺图、控制台错误或数量不全时退出失败，不能用“脚本跑完”代替有效产物。
