# verify-suzhou:用通过的规则手算一座苏州亭与一座北京清代大式殿

日期:2026-09-10。规则取 `docs/qingshi/01`~`06` 各章**"通过"**条;存疑/驳倒条只在显式标注 **(存疑)** / **(驳倒·更正值)** 处引用,作参照不作依据。实测取 08 章"通过"条与 01/02/04 章乙方核到的故宫院刊精测。

**误差定义**:`误差 = (规则值 − 实测值) / 实测值`。判定线 10%(08 章开篇口径)。算不出来的写 **规则缺失**,并指明缺的是"原文无定量"还是"实测缺"。

**尺档声明**(tiers.md §0 元规则 3 要求显式标注):
- A 座(江南)按**苏作尺 1 尺 = 0.275 m** 折算(05 章乙的折算档、06-12 更正值)。
- B 座(北方官式)按**清营造尺 1 尺 = 0.32 m**(01-19、08-19;太和殿档案反推实测锚 32.16 cm)。
- 两档**不得混用**——01-19 乙:混用会系统性放大 16.4%。

## D 对生成器的三条结论

1. **江南亭必须补两个系数**:多边形转角斜长 `2/√3`(六角)、`1/cos(22.5°)=1.082`(八角,同法外推),不得沿用方五斜七 1.4(六角误差 +21.2%);上檐出走 `1.5 × 出檐椽平出`(实得 `0.21 × 柱高`),不得用 03-01 的 `0.3 × 柱高`(偏 +44%)。这两条 tiers.md Tier B/C 已把 03-01、03-16 列入禁用,本次给出了禁用的量化理由。
2. **北方大式的模数方向确认是反的**:攒当、举架、构件断面由斗口推,误差 ≤10%;柱高、步架由斗口推,误差 12%~44%。生成器应按 tiers.md §0 元规则 2 先定开间与柱高、再反算斗口。长春宫实测 `柱高 = 0.66 × 明间面阔`、`檐柱净高 = 52.4 dk`,可与 04-04 乙给的实物区间 52~88 dk 一起作为 clamp 的下界。
3. **步架必须分档**:金步与脊步落在 19.6~20.1 dk(与"檩径 4~5 倍"上端吻合),檐步 39 dk 是另一个量级;任何"全部步架等长"或"总进深均分"的写法都会带来 30% 级误差。举架则可直接用 `[0.5, 0.65~0.7, 0.9~1.02]`,脊步取上限 1.02。
